(00:00) Introduction 👷

Theory:
C is a powerful, general-purpose programming language developed by Dennis Ritchie in the early 1970s. It is widely used for system programming, developing operating systems, embedded systems, and applications where performance is critical. C is known for its simplicity, efficiency, and low-level memory manipulation capabilities. It serves as the foundation for many modern programming languages like C++, Java, and Python.

Code:
No code is required for the introduction, but here’s a simple example to get started:

c
Copy
#include <stdio.h>
int main() {
    printf("Welcome to C Programming!n");
    return 0;
}

Output:

 
Copy
Welcome to C Programming!

Easy Explanation:
Think of C as the “mother” of many programming languages. It’s like learning the basics of how a car engine works before driving a car. Once you understand C, learning other languages becomes much easier. It’s also used in areas where performance and control over hardware are crucial, like robotics or game development.

 Installation & Compiler Setup ☕

Theory:
To write and run C programs, you need a compiler and an Integrated Development Environment (IDE). A compiler translates your C code into machine language that the computer can execute. Popular compilers include GCC (GNU Compiler Collection) for Linux/Mac and MinGW for Windows. IDEs like Code::Blocks, Dev C++, or Visual Studio Code provide a user-friendly interface for writing and debugging code.

Code:
After installing a compiler, you can test it with a simple program:

c
Copy
#include <stdio.h>
int main() {
    printf("Compiler setup successful!n");
    return 0;
}

Output:

 
Copy
Compiler setup successful!

Easy Explanation:
Setting up a compiler is like installing a printer driver on your computer. Without it, you can’t print anything. Similarly, without a compiler, you can’t run your C programs. Once set up, you’re ready to start coding and testing your programs.

Variables, Data Types & Input/Output 🌍 

 

Let’s explore variables, data types, and input/output in the C programming language. These are fundamental concepts for any C program you’ll write.

Variables

In C, a variable is a named storage location in memory where you can store data. Unlike Python, C is statically typed, meaning you must declare the data type of a variable before you can use it.

  • Declaration: You declare a variable by specifying its data type followed by the variable name.

    C
     
    int age;          // Declares an integer variable named age
float height;       // Declares a float variable named height
char initial;      // Declares a character variable named initial
char name[50];    // Declares a character array (string) named name

  • Initialization: You can initialize a variable when you declare it, or you can assign a value to it later.

    C
     
    int age = 30;     // Declaration and initialization
float height;
height = 5.8;    // Assignment

char initial = 'A';
char name[50] = "John Doe"; //Initializing a string

  • Naming Rules:

    • Variable names can contain letters (a-z, A-Z), numbers (0-9), and underscores (_).
    • They must start with a letter or an underscore.
    • They are case-sensitive (my_variable and My_Variable are different).
    • Avoid using C keywords (like int, float, if, for, etc.) as variable names.

Data Types

C has several built-in data types:

  1. Integer Types:

    • int: Integers (whole numbers). int is usually 4 bytes, but the size can vary depending on the compiler and system.
    • char: Characters (single bytes). Often used to represent ASCII characters.
    • short: Short integers (usually smaller than int).
    • long: Long integers (usually larger than int).
    • long long: Very long integers.
    • unsigned: These types (unsigned int, unsigned char, etc.) store only non-negative values.

  2. Floating-Point Types:

    • float: Single-precision floating-point numbers.
    • double: Double-precision floating-point numbers (more precise than float).
    • long double: Extended-precision floating-point numbers.

  3. Other Types:

    • _Bool (C99): Represents boolean values (true or false). Often represented as 1 (true) and 0 (false).
    • void: Represents the absence of a specific type. Used for functions that don’t return a value or for generic pointers.

Input

The scanf() function is used to get input from the user. It requires a format specifier to indicate the data type you expect to read.

C
 
int age;
printf("Enter your age: ");  // Prompt the user
scanf("%d", &age);         // Read an integer (%d format specifier), & is used to get the address

float height;
printf("Enter your height (in meters): ");
scanf("%f", &height);       // Read a float (%f format specifier)

char initial;
printf("Enter your initial: ");
scanf(" %c", &initial);      // Read a character (%c format specifier) - note the space before %c to consume any leftover newline character.

char name[50];
printf("Enter your name: ");
scanf("%49s", name);        // Read a string (%s format specifier) - the 49 limits the number of characters read to prevent buffer overflow.
// or for reading a line with spaces:
// fgets(name, sizeof(name), stdin);

Output

The printf() function is used to display output to the console. It also uses format specifiers.

C
 
printf("Name: %sn", name);      // Print a string (%s)
printf("Age: %dn", age);        // Print an integer (%d or %i)
printf("Height: %.2fn", height); // Print a float, formatted to two decimal places (%.2f)
printf("Initial: %cn", initial);  // Print a character (%c)

Format Specifiers (Commonly Used)

  • %d or %i: Integer
  • %f: Float
  • %lf: Double (use %f for scanf with float, %lf for scanf with double, and %Lf for scanf with long double)
  • %c: Character
  • %s: String (character array)
  • %p: Pointer address

Example: A Simple Program

C
 
#include <stdio.h> // Include the standard input/output library

int main() {
    char name[50];
    int age;

    printf("Enter your name: ");
    scanf("%49s", name); // Limit input to prevent buffer overflow

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Hello, %s!n", name);
    printf("You will be %d years old next year.n", age + 1);

    return 0; // Indicate successful program execution
}

Key Differences from Python:

  • Static Typing: C requires you to declare the data type of variables.
  • Memory Management: C gives you more control over memory, but you are also responsible for managing it (e.g., allocating and freeing memory).
  • Pointers: C has pointers, which are variables that store memory addresses. They are a powerful but potentially complex feature.
  • No Built-in String Type: Strings in C are represented as arrays of characters.
  • Compilation: C code needs to be compiled before it can be executed.

This covers the basics of variables, data types, and input/output in C. These are essential concepts for any C programmer. Practice writing small programs using these elements to solidify your understanding. C is a powerful language, but it requires careful attention to detail, especially when it comes to data types and memory management.

 

Instructions, Expressions & Operators 🔒

Let’s dive into instructions, expressions, and operators in C, which are fundamental to how you write C programs to perform actions and manipulate data.

Instructions

An instruction in C is a single action or command that the computer executes. Instructions are typically terminated with a semicolon (;). Here are some examples:

  • Declaration Instruction: int age; Declares an integer variable named age.
  • Assignment Instruction: age = 30; Assigns the value 30 to the variable age.
  • Function Call Instruction: printf("Hello, world!n"); Calls the printf function to display text on the console.
  • Return Instruction: return 0; Returns a value from a function (often used to indicate successful program execution).

Expressions

An expression is a combination of operators, operands (variables, constants, literals), and function calls that evaluates to a single value. Expressions are used to perform calculations, make comparisons, and manipulate data. Here are some examples:

  • Arithmetic Expression: age + 1 Adds 1 to the value of the variable age.
  • Comparison Expression: age > 18 Checks if the value of age is greater than 18 (evaluates to either 1 (true) or 0 (false)).
  • Assignment Expression: age = 30 Assigns the value 30 to the variable age. The entire assignment is also an expression; its value is the value assigned.
  • Function Call Expression: add(5, 3) Calls the add function with arguments 5 and 3 and returns the result.

Operators

Operators are symbols that perform specific operations on operands. C has a rich set of operators:

  1. Arithmetic Operators:

    • +: Addition
    • -: Subtraction
    • *: Multiplication
    • /: Division (integer division if both operands are integers, floating-point division otherwise)
    • %: Modulus (remainder after division)

  2. Relational Operators (Comparison Operators):

    • ==: Equal to
    • !=: Not equal to
    • >: Greater than
    • <: Less than
    • >=: Greater than or equal to
    • <=: Less than 1 or equal to  
      1. github.com
      github.com

  3. Logical Operators:

    • &&: Logical AND (returns 1 if both operands are true, 0 otherwise)
    • ||: Logical OR (returns 1 if at least one operand is true, 0 otherwise)
    • !: Logical NOT (negates the operand; returns 1 if the operand is 0, 0 if the operand is 1)

  4. Assignment Operators:

    • =: Assignment (assigns the value on the right to the variable on the left)
    • +=: Add and assign (e.g., x += 5 is equivalent to x = x + 5)
    • -=: Subtract and assign
    • *=: Multiply and assign
    • /=: Divide and assign
    • %=: Modulus and assign

  5. Bitwise Operators: (Operate on individual bits of integers)

    • &: Bitwise AND
    • |: Bitwise OR
    • ^: Bitwise XOR
    • <<: Left shift
    • >>: Right shift
    • ~: Bitwise NOT

  6. Increment and Decrement Operators:

    • ++: Increment (increases the value of the operand by 1)
    • --: Decrement (decreases the value of the operand by 1)
    • Pre-increment/decrement: ++x or --x (increments/decrements before the value is used in the expression)
    • Post-increment/decrement: x++ or x-- (increments/decrements after the value is used in the expression)

  7. Conditional Operator (Ternary Operator):

    • condition ? value_if_true : value_if_false; A shorthand way to write a simple if-else statement.

  8. Sizeof Operator:

    • sizeof(operand): Returns the size (in bytes) of the operand (variable or data type).

  9. Member Access Operators:

    • .: Used to access members (variables or functions) of structures and unions.
    • ->: Used to access members of structures and unions through pointers.

Operator Precedence

Operators have precedence, which determines the order in which they are evaluated in an expression. For example, multiplication and division have higher precedence than addition and subtraction. You can use parentheses () to override operator precedence.

C
 
int result = 5 + 2 * 3;   // result will be 11 (2 * 3 is evaluated first)
int result2 = (5 + 2) * 3; // result2 will be 21 (5 + 2 is evaluated first because of the parentheses)

Lvalues and Rvalues

  • Lvalue: An lvalue refers to a memory location that can be assigned a value. Variables are lvalues.
  • Rvalue: An rvalue refers to a value that can be assigned to an lvalue. Literals, constants, and the results of expressions are rvalues.
C
 
int x = 10;  // x is an lvalue, 10 is an rvalue
x = y + 5;   // x is an lvalue, y + 5 is an rvalue

Understanding instructions, expressions, and operators is fundamental to writing C code. Practice using these concepts to build more complex programs and manipulate data effectively. Pay close attention to operator precedence and lvalues/rvalues to avoid common errors.

 

Decision Control Structure (if-else, switch, goto, ternary)

In C, decision control structures allow you to control the flow of your program based on certain conditions. These structures include the if-else, switch, and ternary operators. Note that C does not have a goto statement in the traditional sense like other languages, but it does have goto, which can be used for jumping to another part of the program.

Let’s break down each of these control structures:

1. if-else Statement in C

The if-else statement is the most common decision-making statement in C. It evaluates a condition and executes a block of code if the condition is true, or another block of code if the condition is false.

Syntax:

c
if (condition) {
// Block of code if condition is true
} else {
// Block of code if condition is false
}

Example:

c
#include <stdio.h>

int main() {
int num = 10;

if (num > 0) {
printf("The number is positive.n");
} else {
printf("The number is non-positive.n");
}

return 0;
}

In this example, the program checks if the num is greater than zero. If true, it prints “The number is positive.” Otherwise, it prints “The number is non-positive.”

if-else if-else Ladder:

If you have more than two conditions, you can use an if-else if-else ladder to check multiple conditions sequentially.

c
if (condition1) {
// Block of code
} else if (condition2) {
// Block of code
} else {
// Block of code
}

Example:

c
#include <stdio.h>

int main() {
int num = 10;

if (num > 0) {
printf("The number is positive.n");
} else if (num < 0) {
printf("The number is negative.n");
} else {
printf("The number is zero.n");
}

return 0;
}

2. switch Statement in C

The switch statement is used when you need to check a variable against multiple possible values. It is generally more efficient than using a series of if-else statements when dealing with many conditions.

Syntax:

c
switch (expression) {
case value1:
// Block of code if expression equals value1
break;
case value2:
// Block of code if expression equals value2
break;
default:
// Block of code if expression doesn't match any case
}
  • expression: The value you want to compare.
  • case: A value that expression is compared against.
  • break: Exits the switch block once a match is found. Without break, the code will continue to execute the next case even if the condition was met.
  • default: An optional block executed when no case matches.

Example:

c
#include <stdio.h>

int main() {
int num = 2;

switch (num) {
case 1:
printf("Onen");
break;
case 2:
printf("Twon");
break;
case 3:
printf("Threen");
break;
default:
printf("Number not between 1 and 3n");
}

return 0;
}

In this example, since num equals 2, it will print “Two”. If num were 4, the default case would be executed.

3. goto Statement in C

The goto statement is used to transfer control to another part of the program. It is not recommended to use it in most situations because it can lead to spaghetti code, which is hard to follow and maintain. However, in some cases, it can be useful for jumping out of deeply nested loops or complex error-handling situations.

Syntax:

c
goto label;

label:
// Block of code

Example:

c
#include <stdio.h>

int main() {
int num = 10;

if (num > 0) {
goto positive;
} else {
goto non_positive;
}

positive:
printf("The number is positive.n");
return 0;

non_positive:
printf("The number is non-positive.n");
return 0;
}

In this example, the program jumps directly to the positive label if num > 0.

4. Ternary Operator in C

The ternary operator is a shorthand version of the if-else statement. It is used to evaluate a condition and return one value if the condition is true, and another value if it is false.

Syntax:

c
condition ? value_if_true : value_if_false;

Example:

c
#include <stdio.h>

int main() {
int num = 5;

// Using ternary operator
printf("%sn", (num > 0) ? "Positive" : "Non-positive");

return 0;
}

In this example, if num is greater than 0, it prints “Positive”; otherwise, it prints “Non-positive”.

Summary of Decision Control Structures in C:

  • if-else statement: Executes one block of code if the condition is true, and another if it is false.
  • switch statement: Matches the value of a variable against multiple possible values and executes the corresponding block.
  • goto statement: Allows you to jump to a specific point in the program, though it should be avoided due to readability and maintainability concerns.
  • Ternary operator: A concise version of the if-else statement, useful for simple conditional assignments.

These decision structures help you control the flow of your program depending on conditions, and they are essential for making decisions in your programs.

Iteration & Loop Control Structure 🍕

Let’s explore iteration and loop control structures in C. These structures allow you to repeat blocks of code, making your programs much more powerful and efficient.

1. for Loop

The for loop is used when you know in advance how many times you need to repeat a block of code.

C
 
for (initialization; condition; update) {
    // Code to be executed repeatedly
}
  • Initialization: This part is executed only once, before the loop starts. It’s often used to initialize a loop counter variable.
  • Condition: This condition is checked before each iteration of the loop. If the condition is true, the loop body is executed. If the condition is false, the loop terminates.  
     
  • Update: This part is executed after each iteration of the loop. It’s often used to update the loop counter variable.
C
 
for (int i = 0; i < 10; i++) {
    printf("Value of i: %dn", i);
}

2. while Loop

The while loop is used when you don’t know in advance how many times you need to repeat a block of code. The loop continues as long as a condition is true.

C
 
while (condition) {
    // Code to be executed repeatedly
}
C
 
int i = 0;
while (i < 10) {
    printf("Value of i: %dn", i);
    i++;  // Important: Don't forget to update the loop counter!
}

3. do-while Loop

The do-while loop is similar to the while loop, but the loop body is executed at least once before the condition is checked.

C
 
do {
    // Code to be executed repeatedly
} while (condition);
C
 
int i = 10;
do {
    printf("Value of i: %dn", i);
    i--;
} while (i > 0);  // The loop body executes even though i is initially 10.

Loop Control Statements

  1. break Statement: The break statement is used to terminate a loop prematurely, even if the loop condition is still true.
C
 
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // Exit the loop when i is 5
    }
    printf("Value of i: %dn", i);
}
  1. continue Statement: The continue statement is used to skip the rest of the current iteration of the loop and proceed to the next iteration.  
     
C
 
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {  // Skip even numbers
        continue;
    }
    printf("Value of i: %dn", i); // Prints only odd numbers.
}

Nested Loops

You can nest loops inside other loops. This is useful for iterating over multi-dimensional data structures (like matrices) or performing tasks that require multiple levels of iteration.

C
 
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) {
        printf("i: %d, j: %dn", i, j);
    }
}

Example: Printing a Multiplication Table

C
 
#include <stdio.h>

int main() {
    int n;

    printf("Enter the number for the multiplication table: ");
    scanf("%d", &n);

    for (int i = 1; i <= 10; i++) {
        printf("%d x %d = %dn", n, i, n * i);
    }

    return 0;
}

Choosing the Right Loop

  • Use a for loop when you know the number of iterations in advance.
  • Use a while loop when the number of iterations is not known beforehand and depends on a condition.
  • Use a do-while loop when you need to execute the loop body at least once.

Understanding and using loops effectively is crucial for writing efficient and powerful C programs. Practice using the different types of loops and loop control statements to become comfortable with iteration in C.

 

Functions and Recursion in C

1. Functions in C:

Functions in C allow you to break down your program into smaller, reusable blocks of code. This helps in improving readability, maintainability, and reusability.

Syntax of a Function:

c
return_type function_name(parameters) {
// Body of the function
}
  • return_type: The type of value the function returns (e.g., int, void).
  • function_name: The name of the function.
  • parameters: The input values that are passed to the function (optional).

Example of a Function:

c
#include <stdio.h>

// Function declaration
int add(int a, int b);

int main() {
int result = add(5, 3); // Function call
printf("Result: %dn", result);
return 0;
}

// Function definition
int add(int a, int b) {
return a + b;
}

In this example:

  • The function add takes two integers (a and b) and returns their sum.
  • We call the function in the main function with the arguments 5 and 3, and print the result.

Types of Functions:

  1. Function with a return value and parameters
  2. Function with no return value but with parameters (void functions)
  3. Function with a return value but no parameters
  4. Function with no return value and no parameters

Example: Void Function:

c
#include <stdio.h>

void printMessage() {
printf("Hello, World!n");
}

int main() {
printMessage(); // Function call
return 0;
}

Here, the printMessage function doesn’t return any value, but it performs an action (printing a message).

2. Recursion in C:

Recursion is a technique where a function calls itself to solve a problem. It is commonly used to solve problems that can be broken down into smaller sub-problems.

Recursive Function:

A recursive function consists of two parts:

  1. Base case: This is the condition that stops the recursion.
  2. Recursive case: This is the part where the function calls itself with a smaller input.

Syntax of Recursive Function:

c
return_type function_name(parameters) {
if (base_case_condition) {
return base_value; // Base case
} else {
return recursive_case_value; // Recursive case
}
}

Example of Recursion (Factorial Function):

The factorial of a number n is the product of all positive integers less than or equal to n. Mathematically, n! = n * (n-1) * (n-2) * ... * 1. The factorial of 0 is defined as 1.

c
#include <stdio.h>

// Function to calculate factorial using recursion
int factorial(int n) {
if (n == 0) {
return 1; // Base case
} else {
return n * factorial(n - 1); // Recursive case
}
}

int main() {
int num = 5;
printf("Factorial of %d is %dn", num, factorial(num));
return 0;
}

In this example:

  • The factorial function calls itself with a smaller value of n until it reaches the base case n == 0, at which point it stops and returns 1.
  • The recursive calls build the result as they “return” from the deepest call to the top.

Stack Overflow in Recursion:

Be cautious with recursion, as it can lead to stack overflow if the base case is not reached, or if the recursion depth is too large. This happens because each recursive call uses stack space.

3. Pointers in C (Pointer Basics):

Pointers are a powerful feature in C, allowing you to store the memory address of a variable rather than the variable itself. Pointers enable you to work directly with memory locations, which is useful for dynamic memory allocation, arrays, and function arguments.

1. Pointer Declaration:

c
data_type *pointer_name;
  • data_type specifies the type of data the pointer will point to (e.g., int, float).
  • * indicates that the variable is a pointer.

2. Pointer Initialization:

You can initialize a pointer with the address of a variable using the address-of operator (&).

c
int num = 10;
int *ptr = &num; // ptr now points to the memory address of num

3. Dereferencing a Pointer:

To access the value stored at the memory address the pointer is pointing to, you use the dereference operator (*).

c
int num = 10;
int *ptr = &num;
printf("Value of num: %dn", *ptr); // Dereferencing the pointer to get the value

Example of Pointer Usage:

c
#include <stdio.h>

int main() {
int num = 10;
int *ptr;

ptr = &num; // ptr stores the address of num

printf("Address of num: %pn", ptr); // Prints address of num
printf("Value of num: %dn", *ptr); // Dereferencing ptr to get the value

return 0;
}

In this example:

  • ptr stores the address of num.
  • *ptr dereferences ptr to get the value stored at the address it points to, which is 10.

4. Pointer Arithmetic:

You can perform arithmetic on pointers to access other elements of an array or other memory locations.

c
int arr[3] = {1, 2, 3};
int *ptr = arr;

printf("%dn", *ptr); // Prints 1
printf("%dn", *(ptr + 1)); // Prints 2 (moves the pointer to the next element)

Summary of Key Concepts:

  1. Functions in C allow you to define reusable code blocks with or without parameters and return values.

    • Use functions to break your code into manageable and understandable sections.
    • Example: int add(int a, int b) calculates the sum of two integers.

  2. Recursion is a method where a function calls itself to solve smaller sub-problems.

    • Example: factorial(n) recursively calculates the factorial of a number.

  3. Pointers in C store the memory address of a variable, allowing you to directly manipulate memory.

    • Example: int *ptr = &num stores the address of num, and *ptr dereferences the pointer to access the value.

Data Types (Revisited)

We’ve touched on data types before, but let’s review them in the context of storage classes, as the two concepts are related. Here are the primary data types in C:

  • Integer Types:

    • int: The most common integer type. Usually 4 bytes (but can vary).
    • char: Represents a single character (1 byte).
    • short: Short integer (usually smaller than int).
    • long: Long integer (usually larger than int).
    • long long: Very long integer.
    • unsigned: These types (unsigned int, unsigned char, etc.) store only non-negative values.

  • Floating-Point Types:

    • float: Single-precision floating-point numbers.
    • double: Double-precision floating-point numbers (more precise).
    • long double: Extended-precision floating-point numbers.

  • Other Types:

    • _Bool (C99): Represents boolean values (true or false).
    • void: Represents the absence of a specific type.

Storage Classes

A storage class in C determines the scope, lifetime (duration), and visibility of a variable. There are four main storage classes:

  1. auto (Automatic):

    • Scope: Local to the block (function, loop, etc.) where it’s declared.
    • Lifetime: Exists only while the block is being executed. It’s created when the block is entered and destroyed when the block is exited.
    • Visibility: Only visible within the block.
    • Default: If you don’t specify a storage class, auto is the default for local variables.
    C
     
    void myFunction() {
    auto int x = 10; // Same as int x = 10; auto is rarely used explicitly
    // x is only accessible inside myFunction
}

  2. extern (External):

    • Scope: Global (can be accessed from other files).
    • Lifetime: Exists for the entire duration of the program’s execution.
    • Visibility: Can be accessed from other files (if declared correctly).
    • Used to declare a global variable that is defined in another file.
    C
     
    // file1.c
int globalVar = 20; // Definition

// file2.c
extern int globalVar; // Declaration - tells the compiler that globalVar is defined elsewhere

  3. static:

    • Scope:
      • If declared inside a function: Local to that function.
      • If declared outside a function: Global to the file where it’s declared.
    • Lifetime: Exists for the entire duration of the program’s execution.
    • Visibility:
      • If declared inside a function: Only visible within that function.
      • If declared outside a function: Only visible within the same file.
    C
     
    void myFunction() {
    static int count = 0; // Value is preserved between function calls
    count++;
    printf("Count: %dn", count);
}

int main() {
    myFunction(); // Output: Count: 1
    myFunction(); // Output: Count: 2
    return 0;
}

  4. register:

    • Scope: Local to the block where it’s declared.
    • Lifetime: Exists only while the block is being executed.
    • Visibility: Only visible within the block.
    • Hint to Compiler: A request to the compiler to store the variable in a CPU register for faster access. The compiler might ignore this request. Modern compilers are often better at optimizing register usage than programmers, so register is used much less frequently now.
    C
     
    void myFunction() {
    register int i; // Request to store i in a register
    // ...
}

Summary Table

Storage Class Scope Lifetime Visibility Default
auto Local Within block Within block Yes
extern Global Program duration Across files No
static Local/Global Program duration Within file No
register Local Within block Within block No

Which Storage Class to Use?

  • Use auto (or no storage class) for most local variables within functions.
  • Use extern to share global variables between files.
  • Use static for variables that need to retain their value between function calls (if declared inside a function) or for global variables that should only be accessible within the same file (if declared outside a function).
  • register is rarely used in modern C programming.

Understanding storage classes is essential for writing efficient and well-structured C programs. They allow you to control how variables are stored and accessed, which is crucial for managing data correctly, especially in larger projects. Pay attention to the scope, lifetime, and visibility of variables to avoid common programming errors.

 

Arrays in C

An array is a collection of elements of the same data type stored in contiguous memory locations. Arrays allow you to store multiple values in a single variable and access them using an index.

1. Declaring an Array

The syntax for declaring an array in C is as follows:

c
data_type array_name[array_size];
  • data_type: The type of the elements (e.g., int, float, char).
  • array_name: The name of the array.
  • array_size: The number of elements the array can hold (must be a constant).

Example:

c
#include <stdio.h>

int main() {
int arr[5]; // Declaring an array of 5 integers
return 0;
}

In this case, arr is an array that can store 5 integers. By default, the values of the array are uninitialized, which means they contain garbage values.

2. Initializing an Array

You can initialize an array at the time of declaration.

Example:

c
#include <stdio.h>

int main() {
int arr[5] = {1, 2, 3, 4, 5}; // Initializing the array with values

// Printing the array elements
for (int i = 0; i < 5; i++) {
printf("%d ", arr[i]);
}
printf("n");

return 0;
}

Here, we initialize the array arr with values {1, 2, 3, 4, 5}. The for loop is used to print each element of the array.

3. Accessing Array Elements

You can access individual elements of an array using their index. Array indices start at 0.

Syntax:

c
array_name[index]
  • index: The position of the element you want to access. For example, arr[0] accesses the first element.

Example:

c
#include <stdio.h>

int main() {
int arr[5] = {1, 2, 3, 4, 5};

printf("First element: %dn", arr[0]);
printf("Second element: %dn", arr[1]);

return 0;
}

Here, arr[0] accesses the first element (1) and arr[1] accesses the second element (2).

4. Multi-dimensional Arrays

C allows the creation of multi-dimensional arrays, such as two-dimensional (2D) arrays, which are often used to represent matrices or tables.

Syntax for 2D Array:

c
data_type array_name[row_size][column_size];

Example:

c
#include <stdio.h>

int main() {
int arr[2][3] = {{1, 2, 3}, {4, 5, 6}}; // Declaring and initializing a 2D array

// Printing the elements of the 2D array
for (int i = 0; i < 2; i++) {
for (int j = 0; j < 3; j++) {
printf("%d ", arr[i][j]);
}
printf("n");
}

return 0;
}

In this example:

  • The 2D array arr has 2 rows and 3 columns.
  • The outer for loop iterates through the rows, while the inner for loop iterates through the columns.

5. Array of Strings

In C, a string is an array of characters terminated by the null character (). You can create an array of strings (array of arrays of characters).

Example:

c
#include <stdio.h>

int main() {
char str[3][10] = {"Hello", "World", "C"}; // Array of strings

// Printing each string
for (int i = 0; i < 3; i++) {
printf("%sn", str[i]);
}

return 0;
}

Here, str is a 2D array (array of strings), where each string is an array of characters.

6. Passing Arrays to Functions

Arrays can be passed to functions by referencing their base address. In C, when you pass an array to a function, you actually pass a pointer to the first element of the array.

Example:

c
#include <stdio.h>

void printArray(int arr[], int size) {
for (int i = 0; i < size; i++) {
printf("%d ", arr[i]);
}
printf("n");
}

int main() {
int arr[5] = {1, 2, 3, 4, 5};
printArray(arr, 5); // Passing array to function

return 0;
}

In this example:

  • The function printArray takes an array and its size as parameters and prints the array elements.

7. Array Operations

You can perform various operations on arrays, such as searching, sorting, or modifying elements.

Example: Searching an Element in an Array:

c
#include <stdio.h>

int search(int arr[], int size, int target) {
for (int i = 0; i < size; i++) {
if (arr[i] == target) {
return i; // Element found, return index
}
}
return -1; // Element not found
}

int main() {
int arr[5] = {10, 20, 30, 40, 50};
int target = 30;

int index = search(arr, 5, target);

if (index != -1) {
printf("Element %d found at index %d.n", target, index);
} else {
printf("Element %d not found.n", target);
}

return 0;
}

This program searches for the value 30 in the array and prints its index if found.

8. Dynamic Arrays

Although arrays in C have a fixed size at compile-time, you can create dynamic arrays using dynamic memory allocation (malloc, calloc, realloc, free).

Example of Dynamic Array:

c
#include <stdio.h>
#include <stdlib.h>

int main() {
int n = 5;
int *arr = (int *)malloc(n * sizeof(int)); // Dynamic memory allocation

if (arr == NULL) {
printf("Memory allocation failed.n");
return -1;
}

// Initializing array
for (int i = 0; i < n; i++) {
arr[i] = i + 1;
}

// Printing dynamic array
for (int i = 0; i < n; i++) {
printf("%d ", arr[i]);
}
printf("n");

free(arr); // Free dynamically allocated memory
return 0;
}

Here, malloc is used to allocate memory dynamically for the array. After using the array, we must call free to release the memory.

Strings

let’s delve into strings in C. Unlike many other languages, C doesn’t have a built-in string data type. Instead, strings are represented as arrays of characters, terminated by a null character ().

How Strings are Stored

A string in C is a sequence of characters stored contiguously in memory, followed by a null character (). The null character marks the end of the string. Without it, C wouldn’t know where the string ends.

C
 
char myString[] = "Hello"; // {'H', 'e', 'l', 'l', 'o', ''}

In this example, myString is an array of 6 characters. The characters ‘H’, ‘e’, ‘l’, ‘l’, ‘o’, and ” are stored in consecutive memory locations.

Declaring Strings

You can declare strings in a few ways:

  1. Character Array:

    C
     
    char str1[20];  // Can store up to 19 characters + ''
char str2[] = "Hello"; // Size is automatically determined (6 characters including '')
char str3[6] = "Hello"; // Explicitly specifying the size (must include space for '')

  2. Character Pointer:

    C
     
    char *str4 = "World"; // str4 points to the string literal "World"
    • Important Difference: char str2[] = "Hello"; creates a copy of the string literal in the array str2. char *str4 = "World"; makes str4 point to the original string literal. You cannot modify string literals.

Initializing Strings

C
 
char str1[20] = "Hello"; // Initializing a character array
char str2[20];
strcpy(str2, "Hello");   // Copying a string using strcpy (string copy)

char *str3 = "World";    // str3 now points to "World"

String Manipulation

C provides a set of functions for string manipulation in the string.h header file. You must include this header file to use these functions: #include <string.h>

  • strlen(str): Returns the length of the string (excluding the null character).

    C
     
    char str[] = "Hello";
int length = strlen(str); // length will be 5

  • strcpy(dest, src): Copies the string src to the string dest.

    C
     
    char str1[20];
char str2[] = "Hello";
strcpy(str1, str2); // str1 now contains "Hello"

  • strcat(dest, src): Concatenates (appends) the string src to the string dest.

    C
     
    char str1[20] = "Hello";
char str2[] = ", world!";
strcat(str1, str2); // str1 now contains "Hello, world!"

  • strcmp(str1, str2): Compares two strings. Returns 0 if the strings are equal, a negative value if str1 is less than str2, and a positive value if str1 is greater than str2.

    C
     
    char str1[] = "apple";
char str2[] = "banana";
int result = strcmp(str1, str2); // result will be negative

  • strncpy(dest, src, n): Copies at most n characters from src to dest.

  • strncat(dest, src, n): Appends at most n characters from src to dest.

  • strncmp(str1, str2, n): Compares at most n characters of two strings.

Reading Strings from Input

  • scanf("%s", str): Reads a string from input until a whitespace character (space, tab, newline) is encountered. Important: scanf is vulnerable to buffer overflows if the input is longer than the string array.

  • fgets(str, sizeof(str), stdin): Reads a line from input (including spaces) up to sizeof(str) - 1 characters. It’s safer than scanf for reading strings.

Example: String Reversal

C
 
#include <stdio.h>
#include <string.h>

int main() {
    char str[100];

    printf("Enter a string: ");
    fgets(str, sizeof(str), stdin);

    // Remove the newline character if present
    str[strcspn(str, "n")] = 0;

    int length = strlen(str);
    for (int i = 0; i < length / 2; i++) {
        char temp = str[i];
        str[i] = str[length - i - 1];
        str[length - i - 1] = temp;
    }

    printf("Reversed string: %sn", str);

    return 0;
}

Key Points about Strings in C:

  • Strings are null-terminated character arrays.
  • Use the string functions in string.h for string manipulation.
  • Be careful about buffer overflows when reading strings from input. fgets is generally safer than scanf for reading strings.
  • String literals are immutable (cannot be changed). If you need to modify a string, store it in a character array.

 

Structures in C

A structure in C is a user-defined data type that allows you to group variables of different data types under a single name. Structures are useful when you want to represent a record or an object with multiple attributes.

1. Declaring a Structure

The syntax for declaring a structure is as follows:

c
struct structure_name {
data_type member1;
data_type member2;
// ... more members
};
  • struct: Keyword to define a structure.
  • structure_name: The name of the structure.
  • member1, member2: The individual variables (members) of the structure, which can have different data types.

Example of a Structure:

c
#include <stdio.h>

// Declaring a structure to represent a person
struct Person {
char name[50];
int age;
float height;
};

int main() {
// Creating a structure variable
struct Person p1;

// Assigning values to the members
snprintf(p1.name, sizeof(p1.name), "John Doe");
p1.age = 30;
p1.height = 5.9;

// Printing the values of the structure members
printf("Name: %sn", p1.name);
printf("Age: %dn", p1.age);
printf("Height: %.2fn", p1.height);

return 0;
}

In this example:

  • We define a structure Person with three members: name, age, and height.
  • We create a variable p1 of type struct Person and assign values to its members.
  • We then print the values of the members of the structure.

2. Accessing Structure Members

You can access members of a structure using the dot operator (.).

Example:

c
struct Person {
char name[50];
int age;
float height;
};

int main() {
struct Person p1 = {"Alice", 25, 5.5};

// Accessing structure members using dot operator
printf("Name: %sn", p1.name);
printf("Age: %dn", p1.age);
printf("Height: %.2fn", p1.height);

return 0;
}

Here, we access the name, age, and height members of the structure p1 using the dot operator (p1.name, p1.age, and p1.height).

3. Structure Initialization

You can initialize a structure at the time of declaration.

Example:

c
struct Person {
char name[50];
int age;
float height;
};

int main() {
// Initializing structure at declaration
struct Person p1 = {"Bob", 28, 6.1};

printf("Name: %sn", p1.name);
printf("Age: %dn", p1.age);
printf("Height: %.2fn", p1.height);

return 0;
}

Here, the structure p1 is initialized with values at the time of declaration.

4. Nested Structures

You can also have structures within structures, which is called nested structures.

Example:

c
#include <stdio.h>

// Declaring a nested structure
struct Date {
int day;
int month;
int year;
};

struct Person {
char name[50];
struct Date birthdate; // Nested structure
};

int main() {
struct Person p1 = {"Charlie", {15, 8, 1995}}; // Initialize nested structure

printf("Name: %sn", p1.name);
printf("Birthdate: %02d/%02d/%dn", p1.birthdate.day, p1.birthdate.month, p1.birthdate.year);

return 0;
}

In this example:

  • struct Date is a structure that stores a date.
  • struct Person contains a nested structure birthdate of type struct Date.

5. Structure Pointer

You can also use pointers to access structure members. When using pointers, you use the arrow operator (->) to access the members.

Example:

c
#include <stdio.h>

struct Person {
char name[50];
int age;
float height;
};

int main() {
struct Person p1 = {"Eve", 22, 5.7};
struct Person *ptr = &p1; // Pointer to the structure

// Accessing structure members using pointer and arrow operator
printf("Name: %sn", ptr->name);
printf("Age: %dn", ptr->age);
printf("Height: %.2fn", ptr->height);

return 0;
}

Here, ptr->name, ptr->age, and ptr->height access the members of the structure p1 through the pointer ptr.

6. Passing Structures to Functions

You can pass structures to functions either by value or by reference (using a pointer).

Passing by Value:

When you pass a structure by value, a copy of the structure is passed to the function.

c
#include <stdio.h>

struct Person {
char name[50];
int age;
};

void printPerson(struct Person p) {
printf("Name: %sn", p.name);
printf("Age: %dn", p.age);
}

int main() {
struct Person p1 = {"David", 35};
printPerson(p1); // Passing structure by value

return 0;
}

In this example, p1 is passed by value to the function printPerson, which means that a copy of p1 is used inside the function.

Passing by Reference:

Passing a structure by reference allows you to modify the original structure inside the function.

c
#include <stdio.h>

struct Person {
char name[50];
int age;
};

void updateAge(struct Person *p) {
p->age = 40; // Modifying the original structure through pointer
}

int main() {
struct Person p1 = {"Emma", 30};
updateAge(&p1); // Passing structure by reference

printf("Updated Age: %dn", p1.age);

return 0;
}

Here, we pass a pointer to the structure p1 to the function updateAge, which modifies the original structure.

7. Array of Structures

You can create an array of structures, allowing you to store multiple records.

Example:

c
#include <stdio.h>

struct Person {
char name[50];
int age;
};

int main() {
struct Person people[3] = {{"John", 25}, {"Alice", 30}, {"Bob", 22}}; // Array of structures

for (int i = 0; i < 3; i++) {
printf("Name: %s, Age: %dn", people[i].name, people[i].age);
}

return 0;
}

Here, people is an array of structures, where each element stores the details of a person.

8. Structure and Memory

The size of a structure depends on the sum of the sizes of its members. However, due to padding for alignment, the size of a structure may be larger than the sum of the sizes of its individual members.

Example:

c
#include <stdio.h>

struct Person {
char name[50];
int age;
};

int main() {
struct Person p1 = {"Charlie", 25};
printf("Size of structure: %lu bytesn", sizeof(p1));
return 0;
}

In this example, the sizeof operator returns the size of the structure Person, which may include extra memory due to padding.

Summary of Structures in C:

  1. Declaring Structures: Use struct to define a structure with multiple members.
  2. Accessing Members: Use the dot operator (.) for accessing structure members.
  3. Nested Structures: Structures can contain other structures (nested structures).
  4. Pointers to Structures: Use pointers and the arrow operator (->) to access structure members.
  5. Passing Structures to Functions: Structures can be passed by value or by reference.
  6. Array of Structures: You can create an array of structures to store multiple records.
  7. Memory and Padding: Structures may have padding for alignment purposes.

 

Dynamic Memory Allocation 🧾

Why Dynamic Memory Allocation?

  • Flexibility: You might not know the exact amount of memory you need until your program is running. Dynamic allocation lets you request memory as needed.
  • Efficiency: You can allocate only the memory you need, rather than reserving a fixed amount in advance. This can be especially important when dealing with large data structures or when memory is limited.
  • Dynamic Data Structures: Dynamic memory allocation is essential for creating dynamic data structures like linked lists, trees, and graphs, where the size can change during program execution.

Functions for Dynamic Memory Allocation

C provides several functions for dynamic memory allocation, all found in the stdlib.h header file. You must include this header file to use these functions: #include <stdlib.h>

  1. malloc(): Allocates a block of memory of a specified size.

    C
     
    void *malloc(size_t size);
    • size: The size of the memory block to allocate, in bytes.
    • return value: A pointer to the beginning of the allocated memory block. If the allocation fails (e.g., not enough memory), malloc returns NULL.
    C
     
    int *ptr = (int *)malloc(10 * sizeof(int)); // Allocate space for 10 integers
if (ptr == NULL) {
    fprintf(stderr, "Memory allocation failed!n");
    exit(1); // Exit the program (error)
}

  2. calloc(): Allocates a block of memory for an array of elements and initializes the memory to zero.

    C
     
    void *calloc(size_t num, size_t size);
    • num: The number of elements.
    • size: The size of each element, in bytes.
    • return value: A pointer to the beginning of the allocated memory block. Returns NULL on failure.
    C
     
    int *arr = (int *)calloc(5, sizeof(int)); // Allocate space for 5 integers, initialized to 0
if (arr == NULL) {
   //Handle error
}

  3. realloc(): Resizes a previously allocated block of memory.

    C
     
    void *realloc(void *ptr, size_t size);
    • ptr: A pointer to the previously allocated memory block.
    • size: The new size of the memory block, in bytes.
    • return value: A pointer to the beginning of the reallocated memory block. Returns NULL on failure. The contents of the original block are preserved (up to the smaller of the old and new sizes).
    C
     
    int *ptr = (int *)malloc(5 * sizeof(int));
ptr = (int *)realloc(ptr, 10 * sizeof(int)); // Resize to 10 integers
if (ptr == NULL) {
    //Handle error
}

  4. free(): Releases (deallocates) a previously allocated block of memory. It’s crucial to free memory that you’ve allocated dynamically to prevent memory leaks.

    C
     
    void free(void *ptr);
    C
     
    free(ptr); // Free the memory pointed to by ptr
ptr = NULL; // Good practice: set ptr to NULL after freeing

Important Considerations

  • Error Checking: Always check the return value of malloc, calloc, and realloc to make sure the allocation was successful. If the return value is NULL, the allocation failed.
  • Memory Leaks: If you don’t free dynamically allocated memory, it becomes unavailable for other uses, leading to a memory leak. Memory leaks can cause your program to run out of memory and crash.
  • Dangling Pointers: After you free a block of memory, the pointer that was pointing to it becomes a dangling pointer. Don’t try to access the memory through a dangling pointer; it can lead to undefined behavior. It’s good practice to set pointers to NULL after freeing them.
  • sizeof(): Use the sizeof() operator to calculate the size of data types. This makes your code more portable and less error-prone.
  • void *: malloc, calloc, and realloc return a void * pointer, which can be cast to any pointer type. It’s generally good practice to explicitly cast the return value to the desired type (e.g., (int *)malloc(...)).

Example: Dynamic Array

C
 
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;

    printf("Enter the number of elements: ");
    scanf("%d", &n);

    int *arr = (int *)malloc(n * sizeof(int));

    if (arr == NULL) {
        fprintf(stderr, "Memory allocation failed!n");
        return 1;
    }

    // Use the array (e.g., fill it with values)
    for (int i = 0; i < n; i++) {
        arr[i] = i * 2;
    }

    // Print the array
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("n");

    free(arr);  // Free the memory
    arr = NULL;

    return 0;
}

Dynamic memory allocation is a powerful tool, but it requires careful management to avoid errors. Always check for allocation failures, free allocated memory when you’re done with it, and avoid using dangling pointers. Practicing with dynamic memory allocation will help you write more robust and efficient C programs.

 

 

File Input/Output (I/O) in C

In C, file handling allows you to store data permanently in files and read data from files. The stdio.h library provides functions to perform file input and output operations.

1. File Operations

There are several file operations you can perform:

  • Opening a file
  • Reading from a file
  • Writing to a file
  • Closing a file

Each of these operations is done using specific functions provided by the C standard library.

2. Opening a File

You use the fopen() function to open a file. The function returns a file pointer (FILE *) that you use for subsequent file operations.

Syntax:

c
FILE *fopen(const char *filename, const char *mode);
  • filename: Name of the file to be opened.
  • mode: Mode in which the file should be opened (read, write, append, etc.).

File Modes:

  • "r": Open for reading. The file must exist.
  • "w": Open for writing. If the file exists, it is overwritten. If the file doesn’t exist, it is created.
  • "a": Open for appending. Data is written to the end of the file. If the file doesn’t exist, it is created.
  • "r+": Open for both reading and writing.
  • "w+": Open for both reading and writing. If the file exists, it is overwritten.
  • "a+": Open for both reading and appending.

Example: Opening a file:

c
#include <stdio.h>

int main() {
FILE *file = fopen("example.txt", "w"); // Open file in write mode
if (file == NULL) {
printf("Error opening file.n");
return 1;
}

printf("File opened successfully.n");

fclose(file); // Closing the file
return 0;
}

In this example, we open example.txt in write mode ("w"). If the file cannot be opened, an error message is printed.

3. Writing to a File

Once the file is opened, you can write to it using functions like fprintf(), fputs(), and fwrite().

Example: Using fprintf() to write to a file:

c
#include <stdio.h>

int main() {
FILE *file = fopen("example.txt", "w"); // Open file in write mode
if (file == NULL) {
printf("Error opening file.n");
return 1;
}

// Writing formatted data to the file
fprintf(file, "Hello, world!n");
fprintf(file, "This is a file handling example in C.n");

fclose(file); // Closing the file
return 0;
}

Example: Using fputs() to write to a file:

c
#include <stdio.h>

int main() {
FILE *file = fopen("example.txt", "w");
if (file == NULL) {
printf("Error opening file.n");
return 1;
}

// Writing a string to the file
fputs("Hello, world!n", file);
fputs("This is another example.n", file);

fclose(file);
return 0;
}

In this example, fputs() writes a string to the file. Unlike fprintf(), fputs() is used for writing plain strings.

4. Reading from a File

You can read from a file using functions like fscanf(), fgets(), and fread().

Example: Using fscanf() to read from a file:

c
#include <stdio.h>

int main() {
FILE *file = fopen("example.txt", "r"); // Open file in read mode
if (file == NULL) {
printf("Error opening file.n");
return 1;
}

char buffer[100];

// Reading formatted data from the file
fscanf(file, "%s", buffer);
printf("Read from file: %sn", buffer);

fclose(file); // Closing the file
return 0;
}

Example: Using fgets() to read a line from a file:

c
#include <stdio.h>

int main() {
FILE *file = fopen("example.txt", "r");
if (file == NULL) {
printf("Error opening file.n");
return 1;
}

char buffer[100];

// Reading a line from the file
if (fgets(buffer, sizeof(buffer), file) != NULL) {
printf("Read from file: %s", buffer);
}

fclose(file); // Closing the file
return 0;
}

Here, fgets() reads a line from the file and stores it in the buffer array. It’s safer than fscanf() because it allows you to specify the maximum size of the buffer, preventing overflow.

5. File Pointers

A file pointer is used to keep track of the current position in the file. It moves automatically as you perform operations like reading or writing. You can also manually move the file pointer using functions like fseek(), ftell(), and rewind().

  • fseek(FILE *file, long offset, int whence): Moves the file pointer by offset bytes from the position specified by whence.

    • whence can be:
      • SEEK_SET: Start of the file.
      • SEEK_CUR: Current position.
      • SEEK_END: End of the file.

  • ftell(FILE *file): Returns the current position of the file pointer.

  • rewind(FILE *file): Resets the file pointer to the beginning of the file.

Example: Using fseek(), ftell(), and rewind():

c
#include <stdio.h>

int main() {
FILE *file = fopen("example.txt", "r");
if (file == NULL) {
printf("Error opening file.n");
return 1;
}

// Moving file pointer 10 bytes from the beginning
fseek(file, 10, SEEK_SET);

long position = ftell(file);
printf("Current position: %ldn", position);

// Moving file pointer back to the beginning
rewind(file);

fclose(file); // Closing the file
return 0;
}

6. Closing a File

After completing file operations, you should close the file using the fclose() function to ensure that all data is properly saved and the resources are freed.

c
fclose(FILE *file);

Always ensure you close the file to avoid memory leaks and data loss.

7. Error Handling in File Operations

It’s essential to check whether the file operations are successful. The fopen() function returns NULL if the file cannot be opened, and other functions like fread() and fwrite() return the number of successfully read/written items or 0 in case of an error.

Example of checking for errors:

c
#include <stdio.h>

int main() {
FILE *file = fopen("example.txt", "r");
if (file == NULL) {
printf("Error opening file.n");
return 1;
}

char buffer[100];

// Reading a line from the file
if (fgets(buffer, sizeof(buffer), file) != NULL) {
printf("Read from file: %s", buffer);
} else {
printf("Error reading from file.n");
}

fclose(file); // Closing the file
return 0;
}

8. File I/O with Binary Files

In addition to text files, you can work with binary files, which are used to store data in a format that can be directly read and written by the computer.

Example: Writing to a binary file using fwrite():

c
#include <stdio.h>

int main() {
FILE *file = fopen("data.bin", "wb"); // Open file in binary write mode
if (file == NULL) {
printf("Error opening file.n");
return 1;
}

int numbers[] = {1, 2, 3, 4, 5};

// Writing binary data to the file
fwrite(numbers, sizeof(int), 5, file);

fclose(file); // Closing the file
return 0;
}

Example: Reading from a binary file using fread():

c
#include <stdio.h>

int main() {
FILE *file = fopen("data.bin", "rb"); // Open file in binary read mode
if (file == NULL) {
printf("Error opening file.n");
return 1;
}

int numbers[5];

// Reading binary data from the file
fread(numbers, sizeof(int), 5, file);

// Printing the numbers read from the file
for (int i = 0; i < 5; i++) {
printf("%d ", numbers[i]);
}

fclose(file); // Closing the file
return 0;
}

Summary of File I/O in C:

  1. Opening Files: Use fopen() to open a file in various modes.
  2. Writing to Files: Use fprintf(), fputs(), or fwrite() to write to a file.
  3. Reading from Files: Use fscanf(), fgets(), or fread() to read from a file.
  4. File Pointer: You can use fseek(), ftell(), and rewind() to manage file pointer movement.
  5. Closing Files: Always use fclose() to close a file after operations.
  6. Error Handling: Always check for errors during file operations.
  7. Binary Files: Use fwrite() and fread() to work with binary files.
