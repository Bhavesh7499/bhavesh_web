JavaScript Course Outline with Theory, Practice, and Code

This course is designed to help you learn JavaScript from the basics to advanced concepts. Along the way, we’ll cover practical exercises and build small projects to solidify your learning. Each chapter will include theory, practice exercises, and code examples to demonstrate how JavaScript works in real-world applications.

Ch1: Introduction to JavaScript

Theory

JavaScript is a dynamic scripting language commonly used in web development. It is an essential part of frontend development, allowing interaction with HTML and CSS. JavaScript enables the creation of interactive websites by controlling the behavior of elements on the page. It is also widely used on the server-side with frameworks like Node.js.

JavaScript runs on the client side, which means it is executed in the user’s web browser. This makes it fast and efficient for tasks such as form validation, user input processing, and dynamic updates to web pages without reloading them. JavaScript was first created by Brendan Eich in 1995 and has evolved into one of the most popular languages for web development.

In modern development, JavaScript is used for a wide variety of purposes, including creating animations, building web apps, and even mobile apps with frameworks like React Native. It can be integrated into HTML and CSS, allowing developers to create complex applications that are also user-friendly.

Ch2: Numbers & Strings

Theory

In JavaScript, numbers and strings are two of the most commonly used data types. A number can be an integer (e.g., 5, -10) or a floating-point number (e.g., 3.14, 0.5). JavaScript automatically handles mathematical operations with numbers, including addition, subtraction, multiplication, and division.

A string is a sequence of characters enclosed in quotes (either single ' or double "). Strings in JavaScript are immutable, meaning their values cannot be changed after they are created. However, you can create new strings based on existing ones using methods like concat(), toUpperCase(), and substring().

JavaScript also provides template literals (enclosed by backticks) for string interpolation, which makes it easy to insert variables into strings. This is useful for building dynamic messages.

Ch3: JavaScript with HTML & CSS

Theory

JavaScript is tightly integrated with HTML (HyperText Markup Language) and CSS (Cascading Style Sheets) in web development. While HTML provides the structure of the webpage and CSS defines its presentation, JavaScript brings the page to life by enabling dynamic behavior and interactions.

JavaScript can interact with HTML through the Document Object Model (DOM), which is a hierarchical representation of the HTML elements on the page. JavaScript can read and modify the DOM to change the content and style of elements dynamically. This allows for interactive user interfaces, such as buttons that change color on hover, or form fields that validate input as the user types.

To interact with HTML elements, JavaScript uses methods like getElementById(), querySelector(), and addEventListener(). These methods allow developers to manipulate HTML elements, change their content, and respond to user actions like clicks, form submissions, or key presses.

Ch4: Variables

Theory

A variable in JavaScript is a container for storing data values. You can think of it as a labeled box that holds a value, which can be changed later. Variables are declared using the var, let, or const keywords.

  • var – The original way to declare variables (before ES6). It has function scope.
  • let – Introduced in ES6, let allows you to declare variables with block scope, meaning they are limited to the block of code where they are defined.
  • const – Also introduced in ES6, const is used for variables that should not be reassigned after initialization.

Understanding the scope of variables is important. If a variable is declared within a function, it is accessible only inside that function (local scope). If it’s declared outside any function, it has global scope and can be accessed throughout the entire program.

Ch5: if-else & Boolean

Theory

The if-else statement is used for conditional execution in JavaScript. It allows you to execute different blocks of code based on a Boolean condition (true or false). A basic if statement evaluates an expression, and if the expression is true, it executes a block of code. If the condition is false, it can either do nothing or execute an else block.

  • if – Executes a block of code if the condition is true.
  • else – Executes a different block of code if the condition is false.
  • else if – Used to test additional conditions if the previous condition was false.

Boolean values (true and false) are often the result of comparison operators like ==, >, <, and !=. You can also use logical operators (&&, ||, !) to combine multiple conditions.

Practice Exercise

javascript

console.log(number + " is even.");
} else {
console.log(number + " is odd.");
}
  1. Create a program that checks if a user is eligible to vote based on their age.

} else {
console.log("You are not eligible to vote.");
}

<!DOCTYPE html>

<?php
if (isset($_POST['submit'])) {

$num2 = $_POST['num2'];

switch ($operation) {
case 'add':

  2. When they click “Calculate,” the form is submitted, and the PHP script performs the selected operation.
  3. The result is displayed on the same page.

 

Ch5: If-Else & Boolean

Theory

In JavaScript, if-else statements are used to make decisions in code. They help control the flow of a program based on certain conditions. A condition is often evaluated using Boolean values (true or false).

  • if statement: Executes a block of code if the condition is true.
  • else statement: Executes a block of code if the condition is false.
  • else if statement: Allows you to check multiple conditions.

Boolean Values

In JavaScript, a Boolean is a data type that can either be true or false. These values are commonly used in conditional statements to make decisions.

Example Code:

javascript
let number1 = 5;
let number2 = 3;

if (number1 > number2) {
console.log("Number 1 is greater than Number 2");
} else {
console.log("Number 1 is less than or equal to Number 2");
}

This example checks whether number1 is greater than number2. If it is, it prints "Number 1 is greater than Number 2". If not, it prints "Number 1 is less than or equal to Number 2".

Ch6: Functions

Theory

Functions are reusable blocks of code that can be executed when called. Functions are an essential part of modular programming, allowing you to write code once and reuse it throughout your program.

There are two main types of functions in JavaScript:

  1. Function Declarations – Functions are declared with the function keyword.
  2. Function Expressions – Functions are assigned to variables.

Syntax of a Function Declaration:

javascript
function greet(name) {
console.log("Hello, " + name);
}

In the above example, the function greet takes a parameter name and prints a greeting message.

Ch7: Objects

Theory

In JavaScript, an object is a collection of properties and methods. Properties are values associated with an object, while methods are functions that belong to the object. Objects are crucial in JavaScript for managing structured data and building real-world models.

You can create an object using curly braces {}, and define key-value pairs within the object.

Example Code:

javascript
let car = {
make: "Toyota",
model: "Corolla",
year: 2020,
start: function() {
console.log("Car started");
}
};

In the above example, the car object has properties like make, model, and year, and a method start() to simulate starting the car.

Ch8: JSON, Local Storage, Date & DOM

Theory

  1. JSON (JavaScript Object Notation) is a lightweight data interchange format. It is often used for transferring data between a server and a client. You can parse JSON data into JavaScript objects using JSON.parse(), and convert JavaScript objects into JSON format using JSON.stringify().

  2. Local Storage allows you to store data on the client-side, persistently even when the user reloads or closes the browser. You can use localStorage.setItem() to store data, and localStorage.getItem() to retrieve it.

  3. Date objects in JavaScript are used to handle and manipulate dates and times. You can create a Date object using new Date().

  4. DOM (Document Object Model) represents the HTML structure of the webpage and allows you to manipulate the content, structure, and style of the webpage dynamically using JavaScript.

Example Code for JSON:

javascript
let person = {
name: "John",
age: 30,
city: "New York"
};

// Convert JavaScript object to JSON
let personJSON = JSON.stringify(person);
console.log(personJSON);

// Convert JSON back to JavaScript object
let parsedPerson = JSON.parse(personJSON);
console.log(parsedPerson.name);

Practice Exercise:

  1. Create a program that stores the user’s name in localStorage and displays it on the webpage when the page is reloaded.

Ch9: Arrays & Loops

Theory

An array is an ordered collection of values in JavaScript, allowing you to store multiple items in a single variable. Arrays are zero-indexed, meaning the first element is at index 0.

JavaScript provides several looping mechanisms:

  1. for loop – Runs a block of code a set number of times.
  2. while loop – Runs a block of code as long as a condition is true.
  3. forEach – A method to iterate over arrays.

Example Code for Arrays:

javascript
let fruits = ["apple", "banana", "cherry"];
console.log(fruits[0]); // Output: apple

// Loop through the array
for (let i = 0; i < fruits.length; i++) {
console.log(fruits[i]);
}

Practice Exercise:

  1. Create an array of numbers and write a program that finds the largest number in the array.
  2. Write a function that takes an array of strings and returns a new array where all the strings are uppercase.

Project 2: Todo App

In this project, you will create a Todo App where users can add tasks, mark them as completed, and delete tasks. This project will involve concepts like arrays, functions, DOM manipulation, and local storage.

 

Here’s a simple to-do app written in PHP, including the HTML and PHP code. The app allows users to add and view tasks.

1. PHP Script (todo.php)

php
<?php
// Start session to store tasks
session_start();

// Initialize tasks array
if (!isset($_SESSION['tasks'])) {
$_SESSION['tasks'] = [];
}

// Add task if form is submitted
if ($_SERVER['REQUEST_METHOD'] == 'POST' && !empty($_POST['task'])) {
$_SESSION['tasks'][] = htmlspecialchars($_POST['task']);
}

// Remove task if requested
if (isset($_GET['remove'])) {
$taskIndex = $_GET['remove'];
unset($_SESSION['tasks'][$taskIndex]);
$_SESSION['tasks'] = array_values($_SESSION['tasks']); // Reindex array after removal
}

?>

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Simple To-Do App</title>
<style>
body {
font-family: Arial, sans-serif;
padding: 20px;
}
input[type="text"] {
padding: 8px;
margin-right: 5px;
width: 300px;
}
button {
padding: 8px 15px;
cursor: pointer;
}
ul {
list-style-type: none;
padding-left: 0;
}
li {
margin: 10px 0;
}
.remove {
color: red;
cursor: pointer;
}
</style>
</head>
<body>

<h1>To-Do List</h1>

<form action="todo.php" method="POST">
<input type="text" name="task" placeholder="Add a new task..." required>
<button type="submit">Add Task</button>
</form>

<h2>Task List</h2>
<ul>
<?php if (empty($_SESSION['tasks'])): ?>
<li>No tasks added yet!</li>
<?php else: ?>
<?php foreach ($_SESSION['tasks'] as $index => $task): ?>
<li>
<?php echo $task; ?>
<a href="todo.php?remove=<?php echo $index; ?>" class="remove">Remove</a>
</li>
<?php endforeach; ?>
<?php endif; ?>
</ul>

</body>
</html>

How it works:

  1. Session Storage: Tasks are stored in a PHP session, meaning they will persist as long as the session is active (until the browser is closed).

  2. Adding Tasks: Users can enter tasks through the form. When submitted, the task is added to the session array ($_SESSION['tasks']).

  3. Displaying Tasks: The tasks are displayed in an unordered list (<ul>). If no tasks are available, it shows a default message (“No tasks added yet!”).

  4. Removing Tasks: Users can click on the “Remove” link next to a task to remove it from the list. The task is removed by its index in the session array.

Notes:

  • This is a very basic app and doesn’t persist tasks after the session ends (i.e., when the browser is closed).
  • For a more advanced to-do app, you would want to store the tasks in a database, such as MySQL, or use a persistent storage mechanism like files.

Ch10: Advanced Functions

Theory

Advanced functions in JavaScript include callback functions, higher-order functions, and arrow functions.

  1. Callback functions are functions that are passed as arguments to other functions. They are used for handling asynchronous tasks.
  2. Higher-order functions are functions that can take other functions as arguments or return functions as results.
  3. Arrow functions provide a shorter syntax for writing functions.

Example of Arrow Function:

javascript
const add = (a, b) => a + b;
console.log(add(2, 3)); // Output: 5

  1. Write a function sum that takes an array of numbers and returns the sum using higher-order functions.

Project 3 : Myntra Functional Clone

In this project, you will create a functional clone of Myntra, an e-commerce website. The app will allow users to browse products, add them to a cart, and complete purchases. This project will involve functions, objects, arrays, JSON, local storage, and DOM manipulation.

 

To create a functional clone of Myntra (an e-commerce platform), you would need to build a front-end (UI), back-end (server-side functionality), and connect the two for a fully functional system. Here’s an overview of how you might approach building a simplified clone with basic features using PHP and a front-end framework like HTML, CSS, and JavaScript.

1. Front-End (UI)

For the front-end, you’ll need to create the following pages:

  • Home Page: Display products, categories, and navigation options.
  • Product Page: Details of individual products with options to add to cart.
  • Cart Page: Where the user can view selected items and proceed to checkout.
  • Checkout Page: To finalize the purchase (user details, shipping, payment options).

HTML Example (Home Page)

2. Back-End (PHP)

For the back-end, you’ll need to handle user actions like adding products to the cart, managing the cart, and processing payments.

Example: Adding Products to Cart (PHP)

php
<?php
session_start();

// Sample products data (this would be fetched from a database in a real-world scenario)
$products = [
1 => ['name' => 'Product 1', 'price' => 29.99],
2 => ['name' => 'Product 2', 'price' => 39.99],
3 => ['name' => 'Product 3', 'price' => 49.99]
];

if (isset($_POST['product_id'])) {
$product_id = $_POST['product_id'];

// Initialize cart if it doesn't exist
if (!isset($_SESSION['cart'])) {
$_SESSION['cart'] = [];
}

// Add product to cart
if (isset($products[$product_id])) {
$_SESSION['cart'][] = $products[$product_id];
}

header("Location: cart.php");
exit;
}
?>

3. Cart Page (PHP)

This page will show the products added to the cart and allow the user to proceed to checkout.

php
<?php
session_start();
if (!isset($_SESSION['cart']) || empty($_SESSION['cart'])) {

4. Checkout Page (PHP)

A simple checkout form that captures user details and displays the total amount.

php

if (!isset($_SESSION['cart']) || empty($_SESSION['cart'])) {

?>

5. JavaScript (Add to Cart)

You’ll need JavaScript to handle dynamic interactions such as adding products to the cart without reloading the page.

javascript
document.querySelectorAll('.add-to-cart').forEach(button => {
