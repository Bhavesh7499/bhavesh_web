Level 0: Setup & Fundamentals

1. IDE or Code Editor

Before beginning web development, it’s essential to choose the right tools for writing, editing, and managing code. One of the most important tools for developers is an IDE (Integrated Development Environment) or a Code Editor. These tools provide a structured environment for writing and testing code efficiently. While some developers prefer simple text editors, using a dedicated IDE or advanced code editor significantly enhances productivity.

An IDE is a software application that provides comprehensive features like syntax highlighting, debugging tools, and built-in compilers. It helps developers write clean and efficient code while reducing errors. In contrast, a Code Editor is a lightweight tool that primarily focuses on writing and editing text, often requiring external plugins for additional functionality.

When choosing an IDE or Code Editor, developers must consider factors such as language support, extensibility, and ease of use. A well-configured development environment can save time and effort while improving code quality. In the following sections, we will explore what an IDE is, why it’s needed, how to select one, and how to set up VS Code, one of the most popular code editors for web development.

1.1 What is an IDE?

An Integrated Development Environment (IDE) is a software suite that combines essential tools for software development into a single interface. It typically includes a code editor, a compiler or interpreter, debugging tools, and project management features. IDEs streamline the development process by providing an efficient workflow for writing, testing, and debugging code.

The primary benefit of an IDE is that it brings together multiple development tools, eliminating the need to switch between different applications. For instance, instead of using a separate text editor, terminal, and debugger, an IDE integrates all these features into a single interface. This makes development more organized and productive.

Some IDEs are language-specific, meaning they are designed for particular programming languages. Examples include PyCharm for Python, Eclipse for Java, and WebStorm for JavaScript. Others, like Visual Studio Code (VS Code), support multiple languages through extensions, making them highly versatile.

Example of an IDE in Action

Below is a simple example of an HTML file edited in an IDE (VS Code) with syntax highlighting and live preview:

html
<!DOCTYPE html>
<html>
<head>
<title>My First Webpage</title>
</head>
<body>
<h1>Hello, World!</h1>
<p>This page is written using an IDE.</p>
</body>
</html>

When using an IDE, you can run this file using Live Server in VS Code to see real-time updates.

1.2 Need for an IDE

Using an IDE is essential for developers because it enhances efficiency, reduces errors, and provides a structured environment for coding. Without an IDE, development can be slow, unorganized, and error-prone. One of the biggest advantages of an IDE is code autocompletion, which helps developers write code faster by suggesting syntax, functions, and variables as they type.

Another crucial feature of an IDE is error detection and debugging. IDEs highlight errors in real time and provide debugging tools to fix them quickly. This is especially useful for beginners who may struggle with syntax errors or logic mistakes. Additionally, most IDEs offer integrated version control, allowing developers to manage code changes using Git without leaving the application.

Furthermore, IDEs come with built-in terminal support, which allows developers to run commands directly within the IDE instead of switching to a separate command-line interface. They also provide project management features, making it easy to organize files and dependencies in large projects.

In summary, an IDE is not just a code editor but a complete development environment that improves productivity, reduces errors, and enhances the overall coding experience.

1.3 IDE Selection

Choosing the right IDE depends on several factors, including the programming language, features, and personal preference. Below is a comparison of popular IDEs and code editors:

IDE/Editor Best For Key Features
VS Code Web Development (HTML, CSS, JS) Lightweight, Extensions, Git Integration
WebStorm JavaScript & Frontend Development Smart coding tools, Debugging
Sublime Text Fast and lightweight coding Multi-cursor editing, Plugins
Eclipse Java, C++ Strong debugging, Plugin support

For web development, VS Code is the best choice because it is free, lightweight, and supports HTML, CSS, JavaScript, and PHP with extensions.

Installing VS Code is straightforward and can be done in a few steps:

  2. Run the installer and follow the setup instructions.

  4. Install Extensions (Live Server, Prettier, etc.) to enhance functionality.

To verify installation, open VS Code, create a new file, and save it as index.html. Then write this code:

Save the file and open it in a browser to ensure everything is working.

VS Code can be enhanced with extensions that add extra functionality. Some essential extensions for web development include:

  1. Live Server – Runs a local web server and auto-refreshes the browser.
  2. Prettier – Formats and beautifies code automatically.

Website Components and Fundamentals

Web development consists of multiple aspects, including the client-side and server-side, the role of a browser, and key technologies such as HTML, CSS, and JavaScript. Understanding these fundamental concepts is crucial for building modern, dynamic, and efficient web applications.

1. Client-Side vs Server-Side

Web applications are divided into two main parts: the Client-Side (Frontend) and the Server-Side (Backend). Each plays a different role in delivering a seamless user experience.

The Client-Side refers to the part of a website that is executed on the user’s device (browser). It includes all the elements a user can interact with, such as text, images, buttons, and forms. Technologies like HTML, CSS, and JavaScript power the client side, making web pages visually appealing and interactive. Since this part of the website is loaded directly into the user’s browser, it usually runs faster and requires no server interaction for basic functionalities.

The Server-Side, on the other hand, is where the website’s logic, data processing, and database management occur. This part is executed on a web server, which responds to user requests and returns the required information. Server-side technologies include PHP, Python, Node.js, and Java, which process data, authenticate users, and handle database interactions. Unlike the client side, server-side code remains hidden from users for security reasons.

A web application’s performance depends on the balance between client-side and server-side operations. Some applications, like Single Page Applications (SPAs), rely heavily on the client side, while others, like content-heavy platforms (e.g., blogs, e-commerce sites), use more server-side processing. The correct approach depends on the project’s requirements.

Example Code: Client-Side (HTML + JS)

html
<!DOCTYPE html>
<html>
<head>
<title>Client-Side Example</title>
<script>
function showMessage() {
alert("Hello, this is a client-side JavaScript function!");
}
</script>
</head>
<body>
<button onclick="showMessage()">Click Me</button>
</body>
</html>

Example Code: Server-Side (PHP)

php
<?php
echo "This message is generated on the server and sent to the client.";
?>

2. Frontend vs Backend vs Full-Stack

The roles in web development are categorized into Frontend, Backend, and Full-Stack development. Each has distinct responsibilities, requiring different skill sets and technologies.

Frontend Development is responsible for the visual and interactive aspects of a website. Developers working on the frontend use technologies like HTML, CSS, and JavaScript to create responsive and user-friendly interfaces. Frameworks like React, Angular, and Vue.js enhance frontend capabilities by providing efficient ways to build UI components and handle state management.

Backend Development involves handling the server-side logic, database interactions, and user authentication. Backend developers work with programming languages such as Node.js, Python, PHP, Java, and Ruby. They also use database management systems like MySQL, MongoDB, and PostgreSQL to store and retrieve data dynamically.

Full-Stack Development combines both frontend and backend skills, allowing developers to work on all aspects of a web application. Full-stack developers are proficient in frontend technologies as well as server-side programming and database management. This role requires knowledge of both UI/UX design and server infrastructure, making it one of the most sought-after skills in web development.

Example Code: Full-Stack Web Application (Node.js + HTML)

Frontend (HTML + JS)

html
<!DOCTYPE html>
<html>
<head>
<title>Full-Stack Example</title>
<script>
async function fetchData() {
let response = await fetch('http://localhost:3000/data');
let data = await response.text();
document.getElementById("output").innerText = data;
}
</script>
</head>
<body>
<button onclick="fetchData()">Get Data</button>
<p id="output"></p>
</body>
</html>

Backend (Node.js)

javascript
const express = require('express');
const app = express();app.get(‘/data’, (req, res) => {
res.send(‘Hello from the server!’);
});

app.listen(3000, () => {
console.log(‘Server running on port 3000’);
});

3. Role of Browser

A web browser (such as Chrome, Firefox, Edge) acts as an interpreter and renderer for web pages. When a user requests a web page by entering a URL, the browser sends a request to the web server, retrieves the HTML, CSS, and JavaScript files, and then processes them to display the content visually.

Browsers have built-in engines to handle different types of content. The Rendering Engine (such as Blink for Chrome or Gecko for Firefox) is responsible for displaying web pages, while the JavaScript Engine (like V8 for Chrome) executes JavaScript code. These engines ensure smooth performance and allow users to interact with web applications dynamically.

Browsers also provide developer tools (DevTools), allowing developers to debug, analyze network requests, and inspect elements. This feature is crucial for troubleshooting and optimizing web applications.

Level 1: HTML Basics

In this level, you will dive deeper into the fundamental building blocks of HTML. This includes the creation of your first HTML file, understanding HTML tags, and using Emmet for faster development. We’ll also explore the structure of a basic HTML page and some key concepts like case sensitivity, comments, and utilizing MDN documentation for learning.

1. Starting Up

1.1 First File Using Text Editor

When you begin coding in HTML, the first step is creating a file where you’ll write your HTML code. A text editor is a program that allows you to write and save the code. You can use simple text editors like Notepad (Windows) or TextEdit (Mac), but for a better coding experience, you should use a code editor like VS Code.

To create your first HTML file:

  1. Open your preferred text editor (e.g., VS Code).
  2. Create a new file by selecting File > New File.
  3. Write your first HTML code (we’ll cover this shortly).
  4. Save the file as index.html. The .html extension is important because it tells the computer that the file is an HTML document.
html
<!DOCTYPE html>
<html>
<head>
<title>My First HTML Page</title>
</head>
<body>
<h1>Hello, HTML!</h1>
</body>
</html>

Save the file and open it in any browser to view the result. The browser will render the HTML code and display the content.

1.2 File Extension

The file extension .html or .htm is crucial for the correct interpretation of the file. HTML documents need the .html extension so that web browsers know how to display the content properly. HTML is often paired with other web technologies like CSS and JavaScript, but regardless of how many technologies you combine, the core of a web page will always be in the form of an HTML document.

When you save a file, make sure that the file extension is correct. You might encounter different file types, but for basic web development, .html is the key extension to remember. For example:

  • index.html — The standard name for your website’s main page.
  • about.html — A potential page for an “About” section of your site.

1.3 Opening the Project in VSCode

Once you’ve created your index.html file, it’s time to open the project in VS Code, which is a popular IDE for web development. Here’s how to open your project in VS Code:

  1. Open VS Code: If you haven’t installed it yet, download and install VS Code from the official website.
  2. Open Your Folder: In VS Code, go to File > Open Folder, then select the folder containing your HTML files.
  3. View Your File: Click on your index.html file from the file explorer on the left-hand side to start editing.

VS Code will display the file with syntax highlighting for HTML, making it easier to read and edit. As you work, you can use Live Server (VS Code extension) to see changes in real-time without reloading the page manually.

1.4 Index.html

The index.html file is considered the homepage of any website. When you navigate to a website, the browser first looks for this file by default. The index.html file serves as the entry point to the site, and you’ll typically see it in the root directory of a website’s folder structure.

Here’s an example of a simple index.html structure:

html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>My Website</title>
</head>
<body>
<h1>Welcome to My Website</h1>
<p>This is the first page of my website.</p>
</body>
</html>

The <html> element wraps the entire HTML document. Inside, the <head> section contains metadata like the character set and title, while the <body> contains the visible content.

The index.html file is essential because it helps browsers locate the main page of your site, making it the first file to check when users access your domain.

2. Basics of HTML

2.1 What are Tags?

HTML is built using tags. Tags are the basic building blocks of an HTML document and are used to create the structure and content of a webpage. Tags are enclosed in angle brackets < >. Every tag typically comes in pairs: an opening tag and a closing tag.

  • Opening Tag: <tagname>
  • Closing Tag: </tagname> (Note the slash /)

For example:

  • <h1> and </h1> are opening and closing tags for the heading element.
  • <p> and </p> are opening and closing tags for a paragraph element.

HTML tags define content types like headings, paragraphs, images, lists, links, and more. Tags can also contain attributes which provide additional information about the element.

Here’s an example of an HTML tag with content:

html
<h1>This is a Heading</h1>
<p>This is a paragraph of text.</p>

In this case, <h1> represents the heading tag, and <p> represents the paragraph tag. HTML tags are typically case-insensitive, but it’s a best practice to write them in lowercase.

2.2 Using Emmet to Generate Code

Emmet is a powerful tool integrated into many code editors, including VS Code, that allows you to generate HTML code faster using shorthand notation. This is especially useful for beginners to create complex structures without having to manually type everything.

For example:

  • Typing ! and hitting Tab in VS Code will generate a basic HTML boilerplate.
  • Typing ul>li*5 and hitting Tab will create an unordered list with 5 list items:
html
<ul>
<li></li>
<li></li>
<li></li>
<li></li>
<li></li>
</ul>

This is a huge time-saver when building web pages and helps speed up the workflow.

2.3 Basic HTML Page

The structure of a basic HTML page follows a simple pattern. The page starts with the <!DOCTYPE html> declaration, which tells the browser that it is an HTML5 document. After that, the HTML document is wrapped in the <html> element, and inside it, there are two main sections: <head> and <body>.

html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>Basic HTML Page</title>
</head>
<body>
<h1>Welcome to My First Webpage</h1>
<p>This is a paragraph of text.</p>
</body>
</html>

The <head> section contains meta-information about the webpage (e.g., title, character set). The <body> section contains all the content visible to the user, such as text, images, and links.

2.4 MDN Documentation

The MDN Web Docs (Mozilla Developer Network) is an invaluable resource for learning HTML, CSS, and JavaScript. It provides detailed documentation on every HTML tag, attribute, and API.

The MDN website has clear, structured explanations, examples, and live demos, making it one of the best places to reference while learning or coding. Here’s how to use MDN effectively:

  • Search for a specific tag like <h1> to get a detailed description of its usage and attributes.
  • Review examples and browser compatibility to ensure your code works across different platforms.
  • Learn best practices and coding tips from expert developers.

Link: MDN HTML Documentation

2.5 Comments

HTML comments are non-visible notes written within the code. They help developers leave explanations, reminders, or disable parts of the code during development. Comments in HTML are written between <!-- and -->.

Example:

html
<!-- This is a comment in HTML -->
<p>This is visible content.</p>

Comments are essential for maintaining code, especially when working in teams. They help others (or your future self) understand the purpose of a specific piece of code.

2.6 Case Sensitivity

In HTML, tags and attributes are case-insensitive, meaning that <h1> and <H1> are treated the same. However, it’s best practice to use lowercase for all tags and attributes to ensure consistency and readability.

On the other hand, the attribute values (e.g., class names, IDs) are case-sensitive. For example:

  • <div class="button"> and <div class="Button"> are different.

By adhering to lowercase conventions for tags and attributes, you avoid confusion and maintain code consistency.

Level 2: Must-Use HTML Tags

In this level, we will dive into important HTML tags and attributes that form the foundation of web page content. Understanding how to use these tags is crucial for building well-structured and accessible websites. We will also cover HTML attributes, which provide extra information about elements, and explore common HTML tags for headings, paragraphs, images, links, and other formatting options.

1. HTML Attributes

Attributes provide additional information about HTML elements. They modify the behavior or appearance of the elements they are attached to. Attributes always come inside the opening tag, following the tag name.

1.1 What are HTML Attributes?

An HTML attribute is used to provide more details or configuration options for HTML tags. Attributes are written as a name-value pair (e.g., name="value") and can vary depending on the type of element they are used with. They play a crucial role in controlling the appearance, functionality, and behavior of elements in a webpage.

For example, in an <img> tag, the src attribute specifies the source of the image, while the alt attribute provides alternative text when the image cannot be displayed.

Example of an HTML Element with Attributes:

html
<img src="image.jpg" alt="A beautiful landscape" width="500" height="300">
  • src=”image.jpg” – Specifies the path to the image file.
  • alt=”A beautiful landscape” – Provides a description for screen readers and in case the image doesn’t load.
  • width=”500″ height=”300″ – Defines the size of the image on the webpage.

1.2 Id Property

The id attribute is one of the most commonly used attributes in HTML. It provides a unique identifier for an HTML element. An id must be unique within a webpage, which means no two elements should have the same id value. The id attribute is often used in conjunction with JavaScript or CSS for targeting and styling specific elements.

Example of id Usage:

html
<h1 id="main-title">Welcome to My Website</h1>
<p id="first-paragraph">This is the first paragraph of the website.</p>

In this example, both the <h1> and <p> elements have unique IDs (main-title and first-paragraph), which can be used to target them with CSS for styling or JavaScript for manipulation.

Why Use id?

  • Styling – You can target specific elements in your CSS using their unique id.
    css
    #main-title {
    font-size: 24px;
    color: blue;
    }
  • JavaScript – Access elements by their id for dynamic content changes.
    javascript
    document.getElementById("main-title").innerHTML = "New Title";

2. HTML Tags

HTML tags define the structure and content of your webpage. Below are some essential HTML tags that every web developer should know and use frequently. Each tag serves a unique function in building a webpage.

2.1 Heading Tag (<h1> to <h6>)

Headings are used to define titles or subtitles on a webpage. There are six levels of headings in HTML, ranging from <h1> (largest) to <h6> (smallest). These tags help structure content by dividing it into sections. Search engines also use headings to understand the structure of the content.

Example of Heading Tags:

html
<h1>Main Title of the Webpage</h1>
<h2>Subheading of the Webpage</h2>
<h3>Section Title</h3>
<h4>Subsection Title</h4>
<h5>Minor Heading</h5>
<h6>Smallest Heading</h6>
  • <h1> – Typically used for the main title on a webpage (important for SEO).
  • <h2> to <h6> – Used for subsections or smaller titles, helping to organize the content logically.

2.2 Paragraph Tag (<p>)

The <p> tag is used to define a paragraph of text. It automatically adds space before and after the text to visually separate the content. This is crucial for readability, as text is organized into logical chunks.

Example of a Paragraph Tag:

html
<p>This is a simple paragraph that explains a point on a webpage. Paragraph tags help organize content into readable sections.</p>

Each paragraph should be placed in its own <p> tag, and they can include various other inline elements like links, images, or formatting tags.

2.3 <br> & <hr> Tags

The <br> (line break) tag is used to insert a line break within content, forcing the following content to appear on a new line. It’s an empty tag, meaning it doesn’t have a closing tag.

Example of <br>:

html
<p>This is a line of text.<br>This is the next line of text after a line break.</p>

The <hr> (horizontal rule) tag is used to create a thematic break in the page or a division between sections of content. It produces a horizontal line across the page.

Example of <hr>:

html
<h2>Section One</h2>
<p>This is the first section of content.</p>
<hr>
<h2>Section Two</h2>
<p>This is the second section of content.</p>

The <hr> tag visually separates content, often used for sectioning or creating breaks in long-form content.

2.4 Image Tag (<img>)

The <img> tag is used to embed images into a webpage. It requires the src attribute (source of the image) to specify the image’s path and an alt attribute for accessibility, providing alternative text when the image can’t be displayed.

Example of an Image Tag:

html
<img src="image.jpg" alt="A beautiful landscape" width="500" height="300">
  • src="image.jpg" – Specifies the image’s source file.
  • alt="A beautiful landscape" – Provides descriptive text for screen readers.
  • width="500" and height="300" – Defines the display size of the image.

The <img> tag is crucial for embedding visual content on the web.

2.5 Video Tag (<video>)

The <video> tag allows embedding video content directly into a webpage. It supports multiple video formats and provides controls for users to play, pause, and adjust the volume.

Example of a Video Tag:

html
<video width="640" height="360" controls>
<source src="video.mp4" type="video/mp4">
<source src="video.ogv" type="video/ogg">
Your browser does not support the video tag.
</video>
  • controls – Displays video controls (play, pause, volume, etc.).
  • <source> – Specifies the different video formats for compatibility with various browsers.

2.6 Anchor Tag (<a>)

The <a> tag is used to create hyperlinks, allowing users to navigate between different pages or resources. It requires the href attribute, which defines the target URL.

Example of an Anchor Tag:

html
<a href="https://www.example.com" target="_blank">Visit Example</a>
  • href="https://www.example.com" – Specifies the destination URL.
  • target="_blank" – Opens the link in a new tab or window.

The <a> tag is essential for creating navigation on the web.

2.7 Bold, Italic, Underline, Strikethrough

These tags help to apply text formatting and emphasize content.

  • Bold (<b> or <strong>)
    <strong> indicates strong emphasis (important content), while <b> is simply for bold text without semantic meaning.
    html
    <b>This is bold text</b>
    <strong>This text is strongly emphasized</strong>
  • Italic (<i> or <em>)
    <em> represents emphasized text (often for added meaning), while <i> is used for purely stylistic italics.
    html
    <i>This is italic text</i>
    <em>This text is emphasized</em>
  • Underline (<u>)
    Underline text using <u>.
    html
    <u>This is underlined text</u>
  • Strikethrough (<s> or <del>)
    The <s> tag represents text that has been struck through, while <del> indicates deleted content.
    html
    <s>This is struck through text</s>
    <del>This text has been deleted</del>

3. Character Entity References

What are Character Entity References?

Character entity references allow the inclusion of special characters that are reserved in HTML or cannot be typed directly on a keyboard. These characters are defined by their entity name (e.g., &amp; for &) or numeric code (e.g., © for the copyright symbol).

Examples of Character Entities:

  • &amp; – Represents the ampersand (&) symbol.
  • &lt; – Represents the less-than symbol (<).
  • &gt; – Represents the greater-than symbol (>).
  • &copy; – Represents the copyright symbol (©).

Using character entity references ensures that the web page displays the intended characters without interfering with HTML syntax.

Example of Using Entity References:

html
<p>&copy; 2025 My Company</p>

Level 3: Browser Tools

In this level, we will dive deeper into browser tools, which are essential for web developers in inspecting, debugging, and editing the content of a webpage. These tools help in testing and debugging websites and provide features for live editing, responsive design testing, and validating web pages. Understanding and utilizing these tools will enhance your web development workflow and help you create better websites.

1. Browser Tools

Web browsers come with a built-in set of tools that enable developers to inspect, modify, and debug websites directly from the browser. These tools are invaluable for testing, troubleshooting, and making changes to your code. The main tools developers use include View Page Source, Inspect Element, and HTML without CSS.

1.1 View Page Source

The View Page Source feature allows you to see the raw HTML markup of a webpage, exactly as it was sent from the server to the browser. This tool helps you understand how the page is structured and provides insights into the HTML elements, links, and embedded resources used in the page.

When you right-click anywhere on a webpage and select “View Page Source” (or press Ctrl + U in most browsers), you will see the entire HTML structure of the page, including the <head> section, metadata, and content sections such as paragraphs, images, and links.

This is an excellent way to analyze web page structure without any CSS or JavaScript interference. For example, when viewing the page source of a webpage, you can check the underlying HTML structure without any styling applied. If the HTML is well-structured, it will help you identify the key components that contribute to the layout.

Example of Viewing Source:

If you inspect a page that contains the following HTML:

html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>My Website</title>
</head>
<body>
<h1>Welcome to My Website</h1>
<p>This is a simple webpage.</p>
</body>
</html>

In the “View Page Source” option, you will see exactly this HTML code, without any changes made by JavaScript or CSS.

1.2 Inspect Element

The Inspect Element tool is one of the most powerful browser developer tools. It allows you to interact with and modify the webpage in real-time. When you right-click on any element on the page and select “Inspect” (or press F12 to open Developer Tools), the Elements panel opens. The Inspect Element tool offers a live view of the HTML structure, CSS styles, JavaScript events, and more. It also allows you to modify the HTML and CSS, allowing you to see changes in real-time. This is incredibly useful for debugging, experimenting with layout changes, and testing how changes affect the page without modifying the original source code.

For example, you can edit the HTML directly by double-clicking on text or tags in the Elements panel, and you can also change the CSS styles applied to an element by modifying values directly in the Styles tab.

Example of Inspect Element in Action:

By inspecting the element and changing the text, you can replace it with:

html

1.3 HTML without CSS

This is particularly useful for understanding the semantic structure of a page. Without CSS, all elements will appear in their default format, and you can focus on the content and organization of the HTML tags without being distracted by colors, fonts, or layouts.

2. Responsive Design

Responsive design is essential for making websites look great and function properly on all screen sizes, from desktops to mobile devices. It involves designing and coding web pages that automatically adjust their layout and content based on the viewport size.

2.1 Different Screen Sizes

Responsive web design ensures that a website’s layout adapts to different screen sizes, orientations, and resolutions. It typically uses CSS media queries, which apply different styles based on the screen width. This approach ensures that the webpage remains user-friendly and accessible across a range of devices.

For example, a webpage might display a multi-column layout on larger screens (desktops), but switch to a single column layout on smaller screens (smartphones). Using CSS breakpoints within media queries, you can define styles that only apply when the viewport matches certain criteria, such as screen width, height, and resolution.

Example of Media Queries:

css
/* Styles for screens wider than 600px */
@media (min-width: 600px) {
.container {
display: grid;
grid-template-columns: repeat(2, 1fr);
}
}/* Styles for screens smaller than 600px */
@media (max-width: 599px) {
.container {
display: block;
}
}

This CSS code ensures that the page layout changes based on the screen size, enabling responsive design.

Level 4: HTML and Project Structure

1. Semantic Tags

1.1 Semantic vs. Non-Semantic Tags

In HTML, tags can be divided into semantic and non-semantic tags. Semantic tags clearly define the content they enclose, making the HTML more meaningful for both developers and browsers. Non-semantic tags, on the other hand, do not convey the meaning of the content, they are used only for structuring the layout.

Semantic Tags

Semantic tags such as <header>, <footer>, <article>, <section>, and <nav> provide both structure and context to the document. They help developers and search engines understand the roles of different parts of a page, improving accessibility and SEO. For example, a <header> tag defines the introductory content or navigation of a page, while the <footer> tag indicates the end or copyright information.

Example of Semantic Tags

html
<header>
<h1>Welcome to My Website</h1>
<nav>
<ul>
<li><a href="#">Home</a></li>
<li><a href="#">About</a></li>
<li><a href="#">Contact</a></li>
</ul>
</nav>
</header>
<main>
<section>
<h2>Introduction</h2>
<p>This section introduces the website.</p>
</section>
<article>
<h2>Article Title</h2>
<p>This is an article content.</p>
</article>
</main>
<footer>
<p>&copy; 2025 My Website</p>
</footer>

Non-Semantic Tags

Non-semantic tags, like <div> and <span>, don’t provide any specific meaning about the content they enclose. They are often used for styling or grouping elements, but they don’t give the browser or developers any indication of what the content represents. While these tags are still important, semantic tags should be prioritized wherever possible.

1.2 Why Use Semantic Tags?

  1. SEO (Search Engine Optimization) – Semantic tags improve a webpage’s SEO by making it easier for search engines to interpret and index the content. Search engines like Google give more importance to content inside semantic tags like <article> or <header> because they are more descriptive.
  2. Accessibility – Screen readers and other assistive technologies can use semantic tags to better understand and navigate the content. For example, a screen reader will announce a <header> or <footer> tag, providing context to visually impaired users.
  3. Maintainability – Using semantic tags makes your code cleaner and easier to maintain. Other developers (or even you in the future) will understand the structure and function of the page just by reading the tags.

2. Body Tags

The body of an HTML document is where the content of the webpage resides. It includes everything that users will see in their browser, such as headings, paragraphs, images, and links. Within the body, we can use several tags to organize content into logical sections, making it both readable and meaningful.

2.1 Header Tag (<header>)

The <header> tag defines the introductory content or navigation links of a webpage or section. It typically contains elements such as a logo, site navigation, and headings. The <header> tag is often placed at the top of a page or a section, helping users quickly identify the purpose of that part of the website.

Example of a Header Tag:

html
<header>
<h1>Website Title</h1>
<nav>
<ul>
<li><a href="#">Home</a></li>
<li><a href="#">About</a></li>
<li><a href="#">Services</a></li>
</ul>
</nav>
</header>

Here, the <header> tag contains a heading (<h1>) and a navigation (<nav>) with links.

2.2 Main Tag (<main>)

The <main> tag is used to specify the main content of the document, distinguishing it from other content like sidebars or footers. It should contain the central information related to the page. There should only be one <main> element in the document, and it should not include elements like <header>, <footer>, or <nav>.

Example of a Main Tag:

html
<main>
<section>
<h2>Welcome to Our Website</h2>
<p>This is the main content of the webpage.</p>
</section>
</main>

By using the <main> tag, we define the central part of the page for clarity and better structure.

2.3 Section Tag (<section>)

The <section> tag defines sections of content on a webpage. Each section typically has a heading and relates to a specific topic or area. Sections help break down the content into manageable chunks, making it easier for users to navigate and understand.

Example of a Section Tag:

html
<section>
<h2>About Us</h2>
<p>We are a company that focuses on providing high-quality services to our customers.</p>
</section>

This section contains a heading and content related to the “About Us” topic.

2.4 Article Tag (<article>)

The <article> tag represents a self-contained piece of content that could be independently distributed or reused, such as a news article, blog post, or product description. An article typically includes its own heading, paragraphs, and other media.

Example of an Article Tag:

html
<article>
<h2>Latest Blog Post</h2>
<p>This is the content of the latest blog post. It can be shared or reused independently of other parts of the website.</p>
</article>

Each <article> tag can represent standalone content that can be syndicated or shared.

2.5 Aside Tag (<aside>)

The <aside> tag is used for content that is indirectly related to the main content, such as sidebars, pull quotes, or related links. It provides additional information but is not the primary content of the page.

Example of an Aside Tag:

html
<aside>
<h3>Related Articles</h3>
<ul>
<li><a href="#">How to Improve Your Coding Skills</a></li>
<li><a href="#">10 Web Development Tips</a></li>
</ul>
</aside>

Here, the <aside> tag contains related links that offer more context but are not part of the main flow of content.

2.6 Footer Tag (<footer>)

The <footer> tag defines the footer section of a webpage. It typically includes information such as copyright details, contact information, social media links, and site navigation for users. The <footer> tag is often placed at the bottom of the page, though it can also be used within sections.

Example of a Footer Tag:

html

<nav>
<ul>
<li><a href="#">Privacy Policy</a></li>
<li><a href="#">Terms of Service</a></li>
</ul>
</nav>
</footer>

In this example, the footer contains the copyright notice and links to important policies.

Level 5: Lists, Tables & Forms

In this level, we will cover three essential HTML elements that are foundational for organizing and collecting data on a webpage: Lists, Tables, and Forms. These elements enable content to be structured and interactive, allowing users to view organized data and submit information through web forms. We’ll also cover the iFrame tag, which allows embedding other web pages within a page.

1. List Tag

Lists are used to display multiple items or content in a structured way, making it easier to understand and navigate. HTML offers both ordered and unordered lists to suit different use cases. Let’s explore the different types of lists you can create.

1.1 Ordered Lists (<ol>)

An ordered list is used to present items in a specific sequence. The items in the list are numbered automatically by the browser. The ordered list is enclosed in the <ol> tag, with each list item placed inside an <li> (list item) tag.

Example of an Ordered List:

html
<ol>
<li>First item</li>
<li>Second item</li>
<li>Third item</li>
</ol>
  • Each item in the list is represented by the <li> tag.
  • By default, the list is numbered starting from 1.

1.2 Types of Ordered Lists

HTML allows customization of the numbering style for ordered lists. You can specify different types of markers for list items using the type attribute, which can be one of several values. The common values for type are:

  • type="1" – Default, numbers the list items with numbers (1, 2, 3…).
  • type="A" – Uppercase letters (A, B, C…).
  • type="a" – Lowercase letters (a, b, c…).
  • type="I" – Uppercase Roman numerals (I, II, III…).
  • type="i" – Lowercase Roman numerals (i, ii, iii…).

Example of Ordered List with Different Types:

html
<ol type="A">
<li>First item</li>
<li>Second item</li>
</ol><ol type=“i”>
<li>First item</li>
<li>Second item</li>
</ol>

1.3 Unordered Lists (<ul>)

An unordered list is used to display items where the order does not matter. Instead of numbers, unordered lists use bullet points to mark list items. Like ordered lists, the items are wrapped in <li> tags, and the entire list is wrapped in a <ul> tag.

Example of an Unordered List:

html
<ul>
<li>Apples</li>
<li>Bananas</li>
<li>Cherries</li>
</ul>
  • The browser automatically uses bullets for each item in the list. You can customize the style of the bullets using CSS.

2. Table Tag

Tables are used to display data in rows and columns. They allow for structured presentation of information, such as data grids or charts. A table in HTML is defined by several tags: <table>, <tr>, <td>, and <th>. Here’s how these tags work together.

2.1 <tr>, <td>, and <th> Tags

  • <tr> (Table Row): Defines a row in the table.
  • <td> (Table Data): Defines a data cell in the table (used for each item in the row).
  • <th> (Table Header): Defines a header cell. Text in <th> is usually bold and centered by default.

Example of a Simple Table:

html
<table>
<tr>
<th>Header 1</th>
<th>Header 2</th>
<th>Header 3</th>
</tr>
<tr>
<td>Data 1</td>
<td>Data 2</td>
<td>Data 3</td>
</tr>
<tr>
<td>Data 4</td>
<td>Data 5</td>
<td>Data 6</td>
</tr>
</table>

In this example:

  • The first row (<tr>) contains header cells (<th>) that define the column titles.
  • The subsequent rows contain data cells (<td>) representing individual data points.

2.2 Captions

A table caption is used to provide a title or description for the table. It is placed inside the <table> tag but before the <tr> tag. This helps to clarify the content of the table.

Example of Table Caption:

html
<table>
<caption>Employee Information</caption>
<tr>
<th>Name</th>
<th>Position</th>
</tr>
<tr>
<td>John Doe</td>
<td>Manager</td>
</tr>
</table>

2.3 Colspan

The colspan attribute is used to extend a table cell across multiple columns. This is useful when you need a single cell to span more than one column, like in header or footer rows.

Example of Colspan:

html
<table>
<tr>
<th colspan="2">Personal Information</th>
</tr>
<tr>
<td>Name</td>
<td>John Doe</td>
</tr>
</table>

In this example, the header cell spans across two columns due to the colspan="2" attribute.

3. Forms

Forms are essential for collecting user input. The <form> tag is used to define a form in HTML. Forms can include text fields, buttons, checkboxes, radio buttons, and more. Each input field is defined with an <input> tag.

3.1 Input Tag

The <input> tag is used to create various types of input fields within a form, such as text fields, checkboxes, and buttons. The type attribute specifies the type of input (e.g., text, password, checkbox, submit).

Example of Input Tags:

html
<form action="/submit_form" method="post">
<label for="name">Name:</label>
<input type="text" id="name" name="name"><br><label for=“age”>Age:</label>
<input type=“number” id=“age” name=“age”><br>

<input type=“submit” value=“Submit”>
</form>

  • type="text" creates a text input field for the user to enter their name.
  • type="submit" creates a submit button to send the form data.

3.2 Action Attribute

The action attribute defines the URL where the form data should be sent when the form is submitted. Typically, this is the URL of a server-side script that will process the form data (e.g., a PHP or Node.js script).

Example:

html
<form action="submit_form.php" method="POST">
<!-- Form fields go here -->
</form>

3.3 Name and Value Property

The name attribute specifies the name of the form element, which is sent to the server along with its value when the form is submitted. Each input field’s name is crucial for identifying the data in the form submission.

Example:

html
<input type="text" name="username" value="john_doe">

In this example:

  • The name="username" tells the server to look for a value called username.
  • The value="john_doe" sets the default value for the text field.

3.4 Label Tag

The <label> tag is used to define labels for form elements. It improves accessibility by allowing screen readers to associate text with form controls. The for attribute links the label to a specific form element by referencing its id.

Example of Label Tag:

html
<form>
<label for="email">Email:</label>
<input type="email" id="email" name="email">
</form>

4. iFrame Tag

The <iframe> tag is used to embed another document or web page inside the current page. It allows you to display external content like videos, maps, or other web pages within your webpage.

4.1 Using iFrames

iFrames are commonly used for embedding content like YouTube videos, Google Maps, or even external websites within a webpage. An iframe is an inline frame that lets you load content from another HTML document.

Example of an iFrame Tag:

html
<iframe src="https://www.example.com" width="600" height="400"></iframe>
  • src="https://www.example.com" specifies the URL of the page you want to embed.
  • width and height define the size of the embedded frame.

Why Use iFrames?

  • Embedding External Content – iFrames allow you to display content from other websites without navigating away from your page.
  • Isolation – Content inside an iFrame is isolated from the rest of your page, so it won’t interfere with other scripts or styles.

1. GitHub

1.1 What is Version Control?

Version control is a system that tracks changes to files and enables collaboration between multiple developers. It helps maintain a history of changes, so developers can revert to previous versions of files, understand who made which changes, and work without overwriting each other’s progress.

Version control is critical for any team working on a project, as it provides a centralized way to manage code and ensures that every change is tracked and documented. There are two main types of version control systems:

  • Local Version Control: Simple systems where the entire project is stored on your local machine and changes are tracked in a database.
  • Centralized Version Control (e.g., Subversion): A single central repository is used for storing all project files, and developers check out files to work on them locally before committing changes back to the central server.
  • Distributed Version Control (e.g., Git): Every developer has a local copy of the repository, which contains the full history of changes. Git allows for branching, which lets developers work on separate features independently and merge them back into the main project later.

With distributed version control like Git, each developer’s changes are stored on their local machine and synchronized with the remote repository, making collaboration easier and safer.

1.2 What is Git and GitHub?

Git is a version control system used to manage source code changes. It tracks changes to files, allows branching for new features, and merges changes from multiple developers. Git is an essential tool for any software development project as it helps organize and maintain the integrity of the codebase.

  • Git: Git itself is a command-line tool that allows users to manage project histories, create branches, make commits, and merge changes from different team members. Git is highly efficient and well-suited for large projects.

GitHub is a web-based platform built on top of Git that hosts Git repositories. It provides a graphical user interface (GUI) to interact with Git repositories, making it easier for developers to collaborate on projects.

  • GitHub: GitHub hosts remote repositories and provides tools for managing those repositories online. It offers features like pull requests, issue tracking, and wikis to help teams manage their projects. GitHub is also widely used for open-source development, allowing anyone to contribute to projects and share their code.

GitHub makes it easy to host websites, deploy applications, and share code with the world. It’s a platform that enables seamless collaboration between teams and developers worldwide.

  2. Sign Up: Click on the Sign up button and enter your details (username, email address, password).
  3. Email Verification: After signing up, GitHub will send a verification email. Click the link in the email to verify your account.
  4. Set Up Profile: Complete your profile by adding a bio, profile picture, and other details.
  5. Start Exploring: Once your account is created, you can create repositories, contribute to open-source projects, and more.

1.4 Creating a Repo

A repository (repo) is where all the project files are stored in GitHub. Repos are typically used to store code, documentation, and other related files for a project.

Steps to Create a New Repository:

  2. Click New Repository: On the main dashboard, click the “New” button next to the Repositories tab.
  3. Name Your Repo: Choose a name for your repository. It should be descriptive of the project.
  4. Set Privacy: Choose whether the repository should be public (accessible by anyone) or private (accessible only by you and invited collaborators).

  4. Wait for the Setup: GitHub will automatically configure the environment. You can then start coding directly in the browser.
  5. Work in Codespace: You can edit files, run commands in the terminal, and use Git commands to manage your project.

GitHub Pages is a free, fast way to deploy static websites directly from a GitHub repository.

1.7 Publishing Our Project

To publish a project on GitHub, follow these steps:

    bash
    git push origin main
  2. Access GitHub Pages: Once the code is pushed, access your site via the GitHub Pages URL (e.g., https://username.github.io/repository-name).
  3. Make Changes: Any changes you make to the project files can be pushed to GitHub, and the live site will automatically update.

2. Frameworks

Frameworks like React, Angular, and Vue help build modern web applications by providing structure and tools to develop efficiently. Each of these frameworks has its own strengths and is suited for different types of projects.

2.1 React

React is a JavaScript library developed by Facebook for building user interfaces (UIs). React is primarily used for building single-page applications (SPAs) where dynamic content updates without reloading the entire page. It works based on components, which are reusable code units that manage their own state.

React Code Example:

javascript

import React from 'react';

function App() {
return (
<div>
<h1>Hello, World!</h1>
<p>This is a React application.</p>
</div>
);
}

export default App;

  • Components – React applications are built with small, reusable components.
  • State Management – React components can hold and manage their own state.

React’s main strength is flexibility, and its virtual DOM improves performance by minimizing direct interactions with the actual DOM.

2.2 Angular

Angular is a framework developed by Google for building dynamic web applications. Unlike React, Angular is a full-fledged MVC framework that provides more built-in tools and structure. Angular uses two-way data binding, which means changes in the user interface are automatically reflected in the application’s data model, and vice versa.

Angular Code Example:

html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Angular Example</title>
</head>
<body>
<h1>{{title}}</h1>
<script>
const title = 'Hello, Angular!';
</script>
</body>
</html>

Angular uses dependency injection, which makes it easier to manage components and services. It is also equipped with routing for creating multiple views in a single-page application (SPA).

2.3 Vue

Vue is a progressive JavaScript framework for building user interfaces. Unlike Angular, Vue is incrementally adoptable, meaning you can integrate it into an existing project easily. It’s lightweight and highly reactive, offering two-way data binding similar to Angular.

Vue Code Example:

html
<div id="app">
<h1>{{ message }}</h1>
</div><script src=“https://cdn.jsdelivr.net/npm/vue@2.6.14/dist/vue.js”></script>
<script>
new Vue({
el: ‘#app’,
data: {
message: ‘Hello, Vue!’
}
});
</script>

Vue is ideal for developers looking for a balance between structure and flexibility. It’s also known for its small size and easy learning curve.
